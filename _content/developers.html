Pi 开发者中心

为什么要选择 Pi 平台？

Pi Network 为开发者提供了一个独特的生态系统。不同于其他区块链需要开发者自己去寻找用户，Pi 拥有超过 5500 万已经完成身份验证且极度活跃的先锋。通过我们的生态系统，您的应用可以瞬间触达全球数千万潜在用户。

  • 即时用户群： 无需昂贵的获客成本。
  • 完善的支付系统： 一键集成 Pi 币支付接口。
  • 身份验证支持： 利用 Pi KYC 确保您的用户是真实人类。

Pi SDK

我们的 JavaScript SDK 允许您在几分钟内将现有的 HTML/JS 应用连接到 Pi 区块链，实现认证与支付功能。

开发者测试网

在真实的沙盒环境中测试您的 dApp，并在我们的 Pi 浏览器“生态系统”列表中获得展示位。

入驻流程

  1. 1. 下载 Pi 浏览器

    通过 Pi 浏览器进入 "develop.pi" 应用，创建您的开发者账户。

  2. 2. 注册并配置应用

    在开发者控制台登记您的项目，获取专属的 App ID 和 API 密钥。

  3. 3. 集成与测试

    在测试网进行压力测试，确保支付逻辑和用户体验完美无缺。

🛠️ Pi SDK开发指南

📋

Pi SDK

JavaScript SDK，让你的Web应用集成Pi身份验证和Pi支付功能。支持用户登录、Pi转账、应用内支付等核心功能。

🔑

Pi API

服务端API接口，用于验证用户身份、处理支付回调、管理应用数据。需要在Pi Developer Portal注册应用获取API Key。

🔐

身份验证

Pi的去中心化身份验证系统，5500万+已验证用户，免注册一键登录，比传统OAuth更安全便捷。

💰

Pi支付

集成Pi支付功能，用户可直接用Pi购买你的商品或服务。零手续费，全球无国界，即时到账。

🚀 开发者入门步骤

1

注册开发者账号

在Pi Developer Portal注册，创建你的应用并获取App ID和API Key

2

集成Pi SDK

在你的Web应用中引入Pi SDK JavaScript库，配置App ID

3

实现认证和支付

调用SDK的authenticate()和createPayment()方法，实现用户登录和Pi支付

4

测试和上线

在Pi Browser中测试你的应用，确认功能正常后提交审核上线
