开放网络 100 天：实用性驱动的生态系统

2025-06-19

先锋们，距离上线已经100多天了开放网络！开放网络的发布是 Pi Network 基础设施和生态系统六年多来建设的顶峰，并确保其实用程序在发布时即可使用。

开放网络的外部连接解锁了 Pi 蓬勃发展的生态系统、创新应用程序和广泛的点对点网络，以便与更广泛的区块链世界集成。这也让企业在通过KYB业务后可以与Pi整合验证过程.

开放网络是 Pi 使命的关键：创建一种包容性的、实用驱动的、广泛采用的、任何人都可以访问的加密货币。世界各地的先驱者——加密爱好者、主流普通人以及中间的每个人——都是 Pi 背后的驱动力，因为 Pi 旨在解决大规模采用和现实世界实用性的问题。

在开放网络的前 100 天里，Pi 的生态系统和实用程序持续使先锋受益并不断扩展。让我们回顾一下网络的进步和增长，包括实用程序的关键更新。

Pi Network Ventures：向创新型初创企业投资 1 亿美元

Pi网络风险投资公司是一项以 Pi 和美元持有的 1 亿美元发展计划，由 Pi 基金会发起，旨在对初创企业和企业进行战略投资，包括那些促进 Pi 的实用性、采用和现实世界影响的企业和企业。

其三个主要目标是提高 Pi 的实用性，使世界上更多的产品能够进入 Pi 网络，并将 Pi 带到现实世界。

通过投资初创公司和企业，Pi 寻求为开发人员提供支持，其中许多开发人员使用 Pi 进行构建、集成和创新，并带来现实世界的实用性。 Pi Network Ventures 的投资寻找专注于全球可访问、社区驱动且具有经济意义的项目的创新者。

赌博是一个关键的垂直领域Pi Network Ventures 将重点投资的领域。游戏处于社交互动、注意力经济和虚拟商品等几个关键优势的交汇点，而 Pi Network Ventures 拥有独特的优势，可以利用 Pi Network 帮助游戏开发者实现他们的目标，从而有利于 Pi 生态系统。

为此，Pi Network 推出了水果派，一款有趣的水果配对游戏，还展示了 Pi 现有的游戏实用程序。通过与各种 Pi 产品和实用程序（例如 Pi 广告网络、Pi 钱包和 Pi 支付）集成，FruityPi 已被 Pi Network 用作早期信号，表明游戏如何通过固有的内置社交动态和虚拟经济，同时推动应用程序级别的参与和更广泛的生态系统效用。

  • 注册卖家总数超过 125,000 名——包括58,000名活跃卖家；
  • 使用社区构建的Pi 应用程序地图by超过 180 万先锋;和
  • Pioneers 提交的超过 45,000 条评论.

PiFest 的成功说明了先锋和企业与 Pi Network 的合作，渴望的以 Pi 进行交易。这强化了 Pi Network 建立一个由 Pi 驱动的包容性、点对点生态系统的长期愿景已经实现并将继续扩大。

.pi 域名拍卖：新的平台级实用程序

2025 年圆周率日还推出了.pi 域名拍卖，一个平台级实用程序，利用 Pi 社区的集体资源（注意力、真实性和准备进行交易的大型社区）以及开放网络的外部连接，进一步扩大 Pi 在现实世界商业和数字交互中的作用。

.pi 域名允许个人、应用程序和企业在 Pi 生态系统中竞标并拥有唯一的数字标识符。 .pi 域名已经拥有清晰、直接和可衡量的现实世界用例以及实际应用，这使得 .pi 域名有别于欠发达生态系统中的其他虚拟财产/所有权。

迄今为止，.pi 域名拍卖已收到：

  • 超过 123,000 个活跃投标
  • 超过 57,000 个独特的投标人
  • 超过 69,000 个有效出价的域名
  • 拍卖期间活跃出价总计超过 300 万个 Pi

生态系统界面更新

这生态系统接口列出了先锋可以使用的合格主网应用程序。这延续了 Pi 的使命，即通过提供应用程序和实用程序的访问权限来为先锋和开发人员提供支持，同时为开发人员提供更多机会来展示其应用程序。在开放网络的前 100 天，Pi Network 对生态系统界面进行了多次更新。其中包括：

  • 主网生态系统应用扩展: 满足主网应用部署要求的开发者现在可以直接通过开发者门户申请将其应用添加到主网生态系统接口，而无需等待加入白名单。
  • 改进的生态系统界面设计:生态系统界面设计已更新，通过更简洁的设计和改进的用户体验，改进了先锋社区应用程序的直观导航。
  • Pi Ad Network 应用程序扩展到 Pi Apps：Pi App 开发者现在可以申请加入 Pi Ad Network。被选中的应用程序将加入试点计划中的第一批 Pi Apps，他们现在通过该计划产生并接收广告收入。
  • 新应用程序加入主网生态系统界面:自开放网络以来，新的 Pi 应用程序已添加到主网生态系统接口中，这表明社区、用户和开发人员对 Pi 网络的持续支持，以及开放网络以来整个 Pi 生态系统中应用程序的持续增长。

账户安全、主网迁移、主网钱包激活

自开放网络以来，Pi 继续通过帐户安全更新和主网迁移来支持先锋，并通过主网钱包激活扩展主网可访问性。

  • KYC 验证先锋的完整电话号码变更：通过 KYC 的先驱者现在可以在完成活性验证测试后更新其完整电话号码。
  • Pi 迁移钱包的双因素身份验证 (2FA) 有助于确保 Pioneer 帐户安全: 先驱者需要完成 2FA 以保护并确认其迁移 Pi 钱包。对于那些受此要求影响的先驱者，需要先完成此操作，然后才能将其 Pi 成功迁移到主网区块链。
  • 转向基于电子邮件的 2FA:这种安全措施允许通过受信任的电子邮件进行更容易访问、更安全且更具成本效益的验证。基于电子邮件的 2FA 没有基于短信验证的限制（即由于电信限制、运营商政策、个人服务订阅、成本等造成的地理限制）。
  • 通过新的钱包激活机会扩大 Pi 主网生态系统的可访问性: 主网钱包激活功能使经过身份验证的先驱者（包括完全 KYC 的先驱者、大多数暂时 KYC 的先驱者以及尚未加入 Pi 网络的用户）能够在 Pi 主网区块链上激活他们的钱包。这解除了他们参与 Pi 主网生态系统的障碍，并扩大了 Pi 主网生态系统的包容性。
  • 新帐户恢复选项现已推出: 引入了新的密码重置流程。这适用于为其帐户设置了可信电子邮件的先锋。如果有，他们可以请求重置密码，除了先锋已经可用的现有恢复方法之外，他们还将在受信任的电子邮件地址收到密码重置链接。
  • KYC 更新：Pi Network 还解决了可能阻碍某些先锋通过 KYC 取得进展的各种问题。其中包括识别和修复流程中的小错误、更新以允许 Yoti 用户完全完成流程，以及解决与丢失数据相关的问题。

结论

Pi 在开放网络中的生态系统是由应用程序和实用程序的倡议、真实和实际的用例以及 Pi 社区的参与来定义的。在开放网络的前 100 天里，先锋们已经证明了一种广泛采用的、基于实用程序的 Pi 加密货币将继续存在并发展。先驱者、开发者和企业应该继续在 Pi 上参与和创造，推动网络继续取得有利于整个生态系统的成就。
