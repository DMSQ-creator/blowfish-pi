**为何Pi与其他区块链的感受如此不同？实用性的意义何在？**

Pi之所以与其他区块链感受不同，是因为Pi本就与众不同。一年前开放网络启动时，我曾将Pi描述为"不墨守成规者"，这一特质至今未变。Pi在几个根本层面上独树一帜：我们从未进行过首次代币发行，坚持免费挖矿以确保可及性，采用移动优先策略，Pi主网区块链完全经过KYC认证，拥有全球数千万已验证用户，并且从最初就始终强调实用性。

在更广阔的加密货币行业中，面对数以千计的加密货币和数字资产，交易不可避免地成为主要焦点。交易机制本身——DeFi、流动性、市场基础设施——确实是重要的创新领域。但除了"交易如何发生"之外，还存在一个更根本的问题：人们究竟在交易什么？

Pi致力于解决的不仅是交易是否可行或交易效率问题，而是更具挑战性的命题：什么才值得被交易？如果仅仅是为了实现交易功能，完全可以发行大量虚假或无意义的代币——正如我们甚至在测试网上也常见的那样——交易便能立即启动。只要有人参与，交易量就可能很高。但如果这些代币不映射任何真实价值，这样的交易又有什么意义呢？

真正的难题在于，如何让代币在现实世界的应用场景中发挥作用——无论是用于实体商品与服务的商业交易，还是如何使其能够实质性地参与商业与生产流程。这正是**应用价值**的意义所在。

一直以来，Pi Network 始终强调将 Pi 用于实体商品与服务——无论是在本地商业场景中，还是在 Pi 浏览器内的各类 Pi 应用中，涵盖电子商务、游戏、社交及教育等多个领域。无论是 Pi 本身，还是基于 Pi 构建的生态代币，应用型代币都必须融入具体的产品与真实的使用流程中，而不能仅仅停留在抽象的金融机制层面。

应用价值也与 Pi 对 KYC 身份验证的重视密切相关。Pi 完全经过 KYC 验证的网络，为区块链承载现实世界资产与生产流程奠定了根本基础。

有时人们会问，为什么 Pi 黑客马拉松的获奖应用看起来与典型的加密货币项目如此不同——例如约会应用或电子商务平台，而非纯粹的 DeFi 产品。这种差异是刻意的。Pi 优先考虑的是那些解决现实问题、满足实际需求的应用，而不仅仅是金融机制上的创新。只有当涉及真实应用价值与生产活动时，DeFi 机制才具有意义。实现快速、高流动性的交易很容易；但要让代币在支持现实世界创新与经济活动的真实产品内部流通，则要困难得多。

然而，这条更艰难的道路值得走下去。我们相信，只有坚持不懈地尝试解决这个复杂且具有挑战性的问题——即如何让区块链和加密机制真正用于促进现实世界的生产——Web3 才能实现有意义的突破。这条路可能需要更多时间、更多韧性，并且看起来可能与众不同。但这是 Pi 从第一天起就选择的道路，也是更广泛的加密行业最终必须踏上的道路，以克服其自身面临的挑战。

这一理念可追溯至Pi Network最初的设计。Pi被设计为可自由获取，允许任何人无需经济门槛或自付成本即可参与挖矿。这一设计不仅实现了广泛的分布性和包容性，更让整个网络及其所有参与者能够以足够的耐心，投入到构建基于实用性的完整生态系统所必需的艰巨工作中。已有众多加密货币选择了另一条道路，何不免费尝试Pi的这条路径呢？

**当前网络的工作重点是什么？**

当然，网络将继续推进对先锋至关重要的常规工作，例如KYC认证和主网迁移；同时为开发者完善并扩展工具支持，降低他们在Pi上构建应用的门槛，并通过各类举措促进Pi生态实用性的增长。

KYC认证和主网迁移仍是重中之重。我们正在提升KYC处理能力，为更多用户解除限制，通过进一步在KYC流程中整合人工智能技术来提高速度，并持续推进迁移及二次迁移工作，让更多先锋能够完整参与主网生态系统。此外，我们正按计划于本季度以安全且可扩展的方式推出KYC验证者奖励机制。

在开发者工具与支持方面，我们持续为开发者提供助力，通过改进工具链和简化集成流程来降低在Pi上开发的门槛。这包括推出诸如更快捷的Pi支付配置等新工具，并为开发者启动和扩展实际应用提供持续支持。

人工智能与实用场景的创建同样至关重要。我们正在扩展App Studio的访问范围，新增支付集成功能，并深化人工智能能力，以帮助应用从构想到落地更快地推进。

在网络层面，我们持续优化节点、协议升级，并完善去中心化交易所功能与流动性池等组件——这一切都是为了支持Pi网络上真实、可用的应用与活动。

Pi Network Ventures持续投资于各阶段、各行业的初创企业和成熟项目，核心目标是推动Pi网络在现实世界中的实用价值与生态产出。

最后，Pi Network始终致力于通过Pi Day、黑客松、本地商业活动等多种方式，以及持续关于Pi的发展路径、产品功能、里程碑与生态系统的教育沟通，来支持并培育强大的社区。

**Pi生态代币是什么？主网生态代币的设计理念是怎样的？**

范成雕：Pi生态系统代币是由社区创建并在Pi上发行的代币。正如许多先锋所知，生态系统代币已在测试网发布，我们正在完成其在主网的最终部署。虽然技术和产品显然很重要，但我们认为主网上最关键的因素将是其设计。

正如我在最近的Token2049演讲中所提到的，发行代币的能力是Web3的重要超能力，但更广泛的加密领域存在一个核心问题：代币设计与真实创新之间的错配。大多数其他加密网络上的代币主要充当筹集资金的工具。然而，尽管采用了这种方法，这些项目大多仍未能提供有意义的实用性和创新。我们认为这是一个结构性问题。

但解决方案是什么？从商业角度来看，代币究竟还能用于哪些方面？如果初创企业和企业创始人不能主要将代币用于筹集资金——考虑到发行和运营代币所需付出的努力——他们究竟为何还要这样做？

这正是Pi能够提供独特答案的领域。

Pi的方法是将加密代币直接融入产品和创新的演进过程。

Pi 强烈鼓励并强调聚焦实用性，因为实用性是任何区块链项目长期稳定、可持续发展和成功的基石。Pi 本身是一种实用型代币，我们也同样鼓励 Pi 生态系统中的代币聚焦实用性并服务于实际应用。尽管区块链上可以发行多种类型的代币，但 Pi 目前的启动项目有意鼓励一种基于 Pi 现有资源和基础设施的全新设计架构——专为用户获取而设计的实用型代币。

通过 Pi 启动项目发行的用户获取型代币，意味着项目方通过发行代币来满足其产品获取用户的需求，并将这些代币集成到产品内部的实用场景中；用户通过启动项目获得这些代币，随后即可在相关产品中使用；Pi 币通过质押等方式参与到上述机制中，以协调和推动整个流程。

Pi 在全球拥有数百万用户，其中不仅包括加密原生用户，更重要的是覆盖了主流人群，其中许多人已完成身份验证。对于产品开发者和企业而言，高质量的用户和全球触达能力是产品成功所必需的最宝贵资源。

Pi 的目标是将生态代币设计成强大的工具，帮助初创企业和商业项目获取用户（包括在用户同意的前提下从 Pi 网络获取），并促进其业务增长。对初创企业而言，早期用户获取通常成本高昂。通过使用 Pi 生态代币这类 Web3 工具，初创企业可以降低用户获取成本，同时让用户直接参与项目，获取反馈、测试产品属性和功能，并验证产品是否真正满足人们的实际需求。

已获取的用户也有助于持续监督企业所提供的服务质量——如果产品无法保持实用性、品质和用户参与度，用户最终可能会离开。自然的用户获取和留存机制，会激励项目方创造并提供有价值的服务，这正符合我们的初衷：打造真正具有创新性的实用产品。

另一方面，从用户的角度来看，他们将能自由选择加入并使用不同的产品，就像在Web2中一样。不同之处在于，他们可以通过Pi启动计划、DEX和AMM获取项目发行的实用代币，并在项目产品中使用这些代币。

我们相信，这样的设计能更好地将Web3的独特能力（例如代币发行）与对创新产品的支持相结合。Pi生态代币并非复制现有的代币模型。事实上，我们有意避免传统做法，因为Web3中的许多问题正源于传统代币的设计方式。这一设计也将在实践迭代中不断演进。

同样重要的区别在于Pi平台鼓励启动的项目类型。Pi不侧重于那些主要意图是发行代币、然后试图围绕代币构建业务的发行方，而是优先考虑拥有真实产品的企业——这些企业从解决实际需求出发，进而将代币作为工具，帮助其更好地发展产品。

当然，生态代币也涉及互操作性和标准加密集成等技术考量，Pi在这些方面借鉴了加密领域的通用成果与创新。

Pi关注的不是代币本身，也不是孤立的机制与集成，而是推动有实用价值、以效用驱动的代币，并支持其背后真正的创新。在此基础上，Pi平台将设计工具、实现集成、并提供基础设施支持，以满足这些产品成功与发展所需的实际条件。

**Pi KYC 有何重要意义？下一步是什么？**

正如先锋们所知，我们的社区花费了数年时间，共同构建了 Pi 的 KYC 解决方案——从底层技术和产品设计，到启动一个由人工验证者组成的全球网络，包括建立覆盖世界多个地区的验证者工作流程，以及设计出保护用户隐私的方案。由于先锋们遍布全球，Pi KYC 解决方案必须实现广泛的地理覆盖和可扩展性。除了标准的身份验证之外，Pi KYC 解决方案还将制裁筛查和合规检查整合到一个统一的系统中。

我们选择在 KYC 上投入如此巨大的资源，有几个原因。从 Pi Network 的角度来看，这是保障网络完整性和真实性的基础。我们也希望减少先锋们为验证身份而自掏腰包的需要，从而确保整个社区的可及性。从网络效用和行业角度来看，我们认为 KYC 是 Web3 中一个尚未解决的关键问题，也是区块链技术大规模普及之前必不可少的一步。这些考量促使我们选择内部构建 KYC，而非外包。

但 KYC 不仅仅是 Pi 内部所需。该计划的下一阶段，是将 KYC 本身视为一项服务——即 KYC 作为一种平台能力。

身份认证是与现实世界经济进行任何有意义整合的基础。任何价值的转移、所有权的确立及变更，都不可避免地会引出“参与者是谁？”的问题。这本质上是一个身份问题，因而也是一个 KYC 问题。

短期内，作为我们既有成果的演进，我们将把KYC的技术与产品——重要的是数据本身除外——作为一项服务提供给其他项目，无论是Web3还是传统企业。这意味着提供API接口，允许外部服务大规模采用Pi的KYC解决方案。虽然市场上已有KYC服务商，但Pi的方案在多个方面独具特色：我们的全球地域覆盖能力；可扩展性；结合人工智能与人工验证的混合模式；以及解决方案的完整性——Pi KYC不仅处理身份验证，还涵盖合规性制裁筛查、人工验证工作流、跨网络比对，并支持不同的监管格式要求。我们正在整合掌纹验证等更多模态，以进一步加强匹配与认证能力，适应行业在身份验证领域的技术发展趋势。

从更长远的角度看，Pi Network自身已完成KYC验证这一事实，将成为一项强大的网络级集体资源。用户始终掌握自身身份与数据的控制权，同时他们获得了参与构建在身份验证网络之上的应用的选择权。而这个网络，反过来又能为需要可信人类身份验证的外部服务提供实用价值。

这不仅关乎Pi生态。解决KYC问题是应对Web3领域诸多重大挑战的先决条件，包括现实世界资产上链。更广泛地说，在这个充满机器人和智能体、且它们日益能模仿人类行为的AI驱动世界里，能够回答"谁是真实人类"这个简单却至关重要的问题，正变得不可或缺。

截至目前，我们已经对数千万先锋完成了KYC验证。通过向其他网络和应用程序开放KYC服务，这也将成为引导非Pi用户进入Pi生态系统的重要门户。

**为何Pi聚焦人工智能？人工智能与区块链有何关联？**

人工智能正在从根本上改变世界创造价值和生产的方式。这一转变不可避免地给人类带来了新的挑战。随着人工智能日益驱动生产，传统劳动力不再是财富分配的可靠基础。这引发了一个关键问题：我们如何确保人工智能创造的价值以真正提升所有人整体生活质量的方式进行分配，而不是进一步集中在那些已经掌控资本的人手中？

这正是Pi致力于解决的核心问题。Pi将区块链技术的终极效用视为一种可审计、可扩展的社会分配与再分配机制。过去几年，Pi已构建了一个广泛分布的网络作为实现该目标的基础。但仅拥有分布式网络还不够。要实现这一终极效用，必须将真实的生产——无论是现有的还是新兴的——引入链上。

这一过程面临着重大挑战。对于现有生产形式而言，最大的障碍之一是身份问题：已验证的身份和已验证的所有权。这是大规模现实世界生产迁移至链上的先决条件。Pi Network通过其KYC解决方案投入大量资源解决这一问题，该方案支持全球规模的身份验证，为可信参与链上经济活动奠定了基础。

就新兴生产而言，前景则更为清晰。下一代应用几乎必然是由人工智能驱动或原生基于人工智能的。然而，人工智能应用层仍处于早期阶段。当前，尽管人工智能行业正积极探索更丰富的应用形态——新型社交网络、生产力工具及人工智能辅助工作流——大多数用户与人工智能的交互仍集中于聊天机器人。

因此，在中短期内，Pi在人工智能与区块链交汇领域的聚焦点在于人工智能应用层。Pi App Studio利用人工智能赋能应用开发；更简化的开发者库和工具旨在方便第三方人工智能构建者轻松集成并在Pi生态上进行开发。在战略层面，Pi结合了自下而上与自上而下的方法。自下而上的举措（如App Studio）能够促成大量应用被创建，尽管其中可能存在较高的信噪比——这是预期之中且可接受的。同时，Pi通过Pi Network Ventures以更自上而下、高信噪比的策略作为补充：该机构每年投资经过严格筛选的团队，并以更深度协作的方式与他们共同推进。

在这两种策略之间，是诸如黑客松和开发者计划等中间举措，它们将草根力量与更具结构性的指导相结合。这些策略共同致力于在Pi上引导、培育并扩展一个充满活力的人工智能应用生态系统。

展望未来，Pi对人工智能的参与将延伸至**人工智能基础设施**本身。这包括用于人工智能训练、推理和强化学习的分布式计算。Pi在这方面具有独特优势，因为它已经拥有一个庞大的计算节点网络——超过35万个节点，以及一个全球性的身份验证人类参与者网络。这些参与者可以选择为人工智能训练、数据标注和强化学习提供真实的人类输入，以换取第三方客户支付的加密货币报酬。

分布式人工智能训练在全球范围内仍处于研究阶段。分布式人工智能学习天然契合分布式网络，并可能有助于解决集中式训练的一些局限性——例如数据中心约束、能源集中，以及灾难性遗忘或全局状态瓶颈等问题。尽管仍存在重大挑战，但这些正是需要持续研究和长期投入才能解决的问题。我们正在积极探索，从完全集中式的人工智能训练转向更分布式的方法为何可行、如何高效实现。要将此转化为对人工智能基础设施的有意义贡献，还需要更深入的研究。

人类参与同样是关键组成部分。Pi的已验证人类网络为人工智能系统提供了可扩展、真实的人类输入这一独特资源，并通过基于区块链的原生支付完成报酬结算。这些要素——分布式计算、已验证的人类输入，以及基于区块链的协同机制——共同为人工智能学习与基础设施提供了新的路径。

试图解决世界性难题对任何人而言都是一项长期事业。这意味着尽早起步更为关键，因为任何真正具有护城河价值的事物——无论是技术还是网络效应——都需要时间来构建。例如，Pi Network目前已取得的战略优势与护城河体现在：其KYC系统、规模、数百万身份验证用户网络、数十万计算机节点，以及数千万社区成员的关注与参与，这些都不是一蹴而就的，而是整个Pi社区历经多年努力建设的成果。同样，通过分布式系统为人工智能基础设施做出实质性贡献也极为困难，而这正是我们必须尽早并持续长期探索的原因。
