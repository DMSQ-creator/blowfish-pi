CiDi Games Beta 上线：展现构建于 Pi 之上的力量

2026-05-29

5 月 14 日，CiDi Games 在 Pi 生态系统中上线了其 Beta 应用，推出了一款可通过 Pi Browser 即时访问的 HTML5 游戏平台。

本次 Beta 上线首发了 10 款游戏，涵盖休闲、益智、放置、动作和竞技等类别，同时还配备了技巧锦标赛、通过 CiDiScore 实现的平台进阶系统、Pi ELF 伙伴体验、Elf Continent，以及面向 Pi 集成游戏的开发者基础设施。这些功能共同使 CiDi Games 成为一个平台级体验，将游戏玩法、身份认同、社区参与和开发者机会汇聚于一个由 Pi 驱动的环境中。

CiDi Games 是 Pi Network Ventures 的投资组合公司，它为先锋者提供了一种通过游戏使用 Pi 的新方式，同时也在不断扩展 Pi 生态系统，提供能够支持更多游戏和开发者的基础设施。

在 Pi 上展现自然增长动力

上线不到一周，CiDi Games 即自然吸引了来自 160 多个国家和地区的超过 81,000 名先锋者。这些活动转化为了更深层次的参与：游戏会话总数超过 120 万次，竞赛/锦标赛参与者超过 21,000 人。

CiDi Games 记录了显著的广告展示量，这突显了 Pi 上的应用只要创作者构建基于实用性的、引人入胜的应用，就可以通过 Pi Ad Network 从真实用户开始变现。

CiDi Games 在 Pi 生态系统目录质押中的应用排名共获得了 319 万 Pi 的质押支持，其中绝大多数由社区质押，使其成为质押量最高的 Pi 应用之一。质押是先锋者和企业支持他们在生态系统界面中创建、使用和喜爱的应用的一种可选方式，同时向开发者传递社区兴趣的可见信号。

这些一周内的成果完全是自然增长的结果，并非由 Pi 官方账号的推广所驱动。先锋者们完全是自主发现并参与 CiDi Games 的。这表明，任何应用只要构建得当并满足真实用户需求，就有机会在 Pi 生态系统中找到有意义的参与，而无需额外的用户获取成本。

CiDi Games Beta 上线所揭示的关于 Pi 平台和构建于 Pi 之上的启示

CiDi Games Beta 上线的自然增长动力，展示了 Pi 对开发者日益严峻挑战的解决方案：构建应用变得越来越容易，但触达真实用户却越来越困难。

Pi 平台将开发者或创作者与一个庞大且活跃的先锋者社区连接起来，并支持满足人类需求的应用体验。

对于开发者或创作者而言，Pi 生态系统不仅是发布应用的地方，更是一个应用可以被真人发现、使用、支持和改进的平台。CiDi Games 的 Beta 上线展示了 Pi 基础设施如何支持交互式产品，同时让开发者接触到 6000 万+ 活跃先锋者社区、Pi 原生参与机制以及变现工具，从而帮助迭代产品并维持持续开发。

任何开发者都可以通过构建和部署满足真实人类需求的 Pi 应用来受益于 Pi 生态系统所提供的优势。请通过 Pi Browser 上的 Pi Developer Portal 提交申请。

对于使用 Codex、Claude Code、Replit、Cursor、Lovable 等外部 AI 工具或其他 AI 辅助编码工具的构建者，你可以通过 Pi App Studio 最近发布的开发者工具轻松将你的应用转换为 Pi 应用，在那里你可以使用现成的 AI 提示词来集成 Pi SDK、验证设置并添加 Pi 支付功能。Pi App Studio 还便于将你的应用部署到 Pi 生态系统中，并让它像 CiDi Games 一样轻松地获取和吸引用户。

除了增长动力和参与度之外，Pi 应用还已与 Pi Network 的其他基础设施组件集成：全球支付、Pi Wallet、Pi Ad Network 和社交网络接入。

在 Pi 生态系统中持续推进应用开发与集成

在与 Pi 的合作中，CiDi Games 将继续收集反馈、改善用户体验、优化平台功能并扩展其游戏库。真实的使用情况为开发者提供持续反馈，让他们了解哪些有效、哪些可以改进，以及新的实用性可能在哪里出现。

在 Pi Browser 中打开 CiDi Games，体验 Beta 应用，畅玩即时访问的游戏，探索全新的 Pi 驱动游戏体验！
