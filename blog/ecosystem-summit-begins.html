Pi生态峰会今天开幕！

2026年11月17日

Pi Network 首届生态系统峰会于今日正式开幕！在接下来的三天里，本次线上峰会将带来全新开发者平台发布、开发者对话和技术演示，重点展示助力拓展 Pi 全生态实用性的各项工具与应用程序。

以下是今日视频节目的日程安排：

  • 开幕致辞：由 Pi Network 创始人范成焘（Chengdiao Fan）发表。

欢迎在今日太平洋标准时间上午 8:00 / 协调世界时下午 4:00 观看以下峰会首播视频！

峰会将于明天（11 月 18 日）继续进行，届时将带来更多技术演示、开发者对话以及全新重磅发布！

11 月 19 日将启动全新的 Pi 黑客马拉松——Pi Next，奖金池高达 200,000 USDT。黑客马拉松将为开发者提供机会，利用 Pi 的开发者平台、SDK 以及内置的 Pi 身份验证和支付功能，为 Pi 庞大且已通过 KYC 认证的用户群体构建现实应用。

欢迎访问 Pi 生态系统峰会专属落地页获取所有峰会内容，包括演讲视频、公告发布、技术演示和黑客马拉松信息。该页面将在为期三天的活动期间随着新内容的发布持续更新。

请继续阅读，了解生态系统峰会第 1 天推出的新工具、新功能、新计划以及重磅发布的更多详情！

在 Pi 上构建与发展应用程序

在 AI 开发日益普及的时代，触达用户并保持用户活跃度是开发者面临的重要挑战。Pi 通过提供简化应用开发的工具，以及让开发者能将其产品与真实用户相连接的成熟生态系统，全面解决了这一过程中的双重难题。

Pi 为构建者提供了触达全球超过 6000 万活跃先锋（Engaged Pioneers）社区、去中心化人类基础设施生态系统以及由 420,000 多个节点构成的网络途径。Pi 的基础设施还为开发者提供用户认证、Pi 支付、已验证身份、兼容 AI 的开发、商业化变现和应用发现等功能，帮助他们将应用推向成熟的先锋社区，并将 Pi 的平台和集体资源转化为切实的实用价值。

AI 辅助开发：全新开发者网页控制台与 MCP

开发者和创作者现在可以使用 AI 代理来构建和注册应用，将其与 Pi 的 API 集成，并申请在 Pi 生态系统中上架！这种全新的 AI 辅助开发体验简化了将应用引入 Pi 的流程，大幅减少了传统开发者入驻与集成过程中的阻碍与工作量。

通过基于浏览器的全新开发者网页控制台（集成基于模型上下文协议（MCP）构建的 Pi 开发者工具），开发者可以将兼容的 AI 编程代理连接到 Pi 的开发者工具，并使用自然语言指令来执行支持的设置与集成任务。这包括创建和注册 Pi 应用、配置应用设置和 URL，以及接入 Pi 身份验证和 Pi 支付等 Pi API。

开发者无需手动操作繁琐的配置步骤、查阅文档页面和穿梭于各个开发者界面之间，而是可以使用 AI 代理来处理大部分技术设置与实施工作，并在需要时由人工进行授权。开发者网页控制台还提供了一个用于管理应用和获取开发者资源的集中式界面，同时支持传统开发工作流和 AI 辅助工作流。这些功能既面向构建全新应用的开发者，也面向将现有应用迁移至 Pi 的团队，包括专业开发者、初创企业以及使用 AI 编程工具的创作者。

从更广泛的意义上讲，这降低了在 Pi 上进行开发的技术门槛，使平台能够面向更广泛的创作者开放，同时简化了开发与集成流程。今天，Pi Network 创始人 Nicolas Kokkalis 博士主持演示了 AI 代理如何与 Pi 的开发者工具进行交互，带领应用完成在 Pi 平台上的注册、配置和集成全流程。

全新生态增长激励与营销预算

Pi Network 正式宣布推出“应用增长计划”（App Growth Initiative）：这是一项营销预算高达 2000 万 Pi 的全新计划。该计划由 Pi 基金会赞助，旨在帮助开发者吸引用户，并鼓励用户更深入地参与 Pi 生态系统中的应用程序。

在该计划下，符合资格的开发者可根据其应用的优势和实际表现，申请获得这部分营销预算的扶持。随后，开发者可以利用这一由 Pi 出资的激励计划来触达并吸引通过 KYC 认证的用户，而无需自行承担奖励资金。例如，当一名符合条件的已通过 KYC 认证的先锋邀请另一名同样符合条件的已认证先锋使用参与该计划的应用时，推荐人和新用户均可从基金会赞助的激励预算中获得一定数量的 Pi，作为符合资格的参与奖励。关于具体资格要求和奖励数额的更多细节将在随后公布。

该计划旨在帮助开发者直接触达 Pi 现有的、已完成身份验证且已迁移至主网的用户网络，而无需自行出资构建独立的引流与用户获取体系。整体激励预算将根据应用质量、实用性以及表现出的用户参与度等指标，在各参与应用之间进行分配，表现更出色的应用有望获得更大规模的支持。

从更宏观的角度来看，应用增长计划旨在将 Pi 自身的网络增长基础设施开放给生态系统开发者。它将资金直接嵌入到用户增长机制中，运用了 Pi 在自身网络发展过程中积累的有效策略。该计划通过成熟的增长机制引导这些资源流动，旨在帮助应用获取并留住真实用户。这种方式在加强对开发者支持力度的同时，也有助于确保网络的生态增长资源得到高效投放，并与真实的用户参与深度绑定。

开发者激励措施与全新改版的 Pi 应用目录

Pi 正在引入新机制，以激励开发者构建高质量、高参与度的应用程序。开发者激励计划通常通过曝光度、经济激励或荣誉地位来奖励开发者。曝光度能够提供更优质的分发机会；经济激励可包括开发成本补贴或折扣（例如，Pi App Studio 为其实际效用显著并吸引真实用户的应用创作者提供补贴价格）；而荣誉地位奖励则体现了开发者的声誉指标。

作为推行这些开发者激励机制的一部分，Pi 对 Pi 应用目录（Pi App Directory）进行了重大改版，为先锋们引入了发现应用的新途径，并为开发者扩大了在全生态触达用户的曝光机会。

在保留“生态目录质押”（Ecosystem Directory Staking）作为核心发现与排名机制的同时，新版目录还引入了基于用户兴趣、增长趋势和活跃度来重点推荐应用的新板块：

  • 收藏应用（Bookmarked Apps）：方便先锋轻松访问并重新打开他们喜爱的应用。

这些更新为优质新应用提供了凭实力获取曝光的渠道。这将激励开发者打造更出色、更具吸引力的应用，从而赢得更多曝光奖励。

综合来看，这些改变体现了 Pi 强化应用分发能力的更广泛举措。通过创造更多依据真实用户互动来获取曝光的机会，改版后的应用目录不仅鼓励开发者专注于打造实用、高质的产品，同时也帮助先锋们发掘更多使用 Pi 的场景。

Pi Launchpad、DEX 与 AMM 将于 2027 年第一季度登陆主网

Pi Launchpad、去中心化交易所（DEX）和自动做市商（AMM）功能将于 2027 年第一季度正式上线主网！这些功能此前已在测试网上经过了多轮迭代，它们将为主网生态代币发行提供额外的基础设施支持，赋能那些整合代币用于特定效用场景的开发者与应用。

这一明确承诺为开发者和生态参与者设定了时间规划，以便为主网代币发行做好充分准备。随着 Pi 持续推出简化应用开发并吸引更广泛开发者的全新工具、资源和项目，Pi Launchpad、DEX 和 AMM 将提供完备的基础设施，为生态系统下一阶段的发展注入动力。

2027 年第一季度这一时间节点，也让包括参与 Pi 即将举办的黑客马拉松项目在内的潜在 Launchpad 候选团队，有充裕的时间构建并准备其应用，以迎接潜在的代币发行。

链上订阅智能合约

Pi 的链上订阅智能合约使开发者能够在其应用中构建定期自动付款服务，支持诸如服务会员、游戏、在线工具、流媒体平台以及其他基于订阅制的产品等丰富场景。

该功能于 2026 年 4 月首次在 Pi 测试网推出，解决了基于区块链实现订阅服务所面临的普遍痛点。虽然订阅模式在传统数字服务中广泛普及，但在区块链上实现该功能往往需要频繁的用户交易授权、预付款充值或额外的基础设施支持。

Pi 的解决方案允许用户自主设定消费预算上限和订阅周期（例如按月扣费，订阅期设为 6 个月），而无需每次续费时都单独签名确认。用户可随时延长或取消订阅，且资金在每笔支付实际发生前始终保留在用户自己的钱包中，无需预先锁定或转出。

如今，除了智能合约本身之外，Pi 钱包和开发者平台等相关配套支持设施均已就绪，全面支持用户和开发者获得端到端的完整订阅体验。

在峰会第 1 天的演示中，Pi Network 展示了开发者如何将该测试网功能集成到其应用中，包括订阅配置、用户授权和支付结算全流程。

Pi 测试网已集成 x402 支付协议

x402 是一项开放支付协议，它利用 HTTP 402 Payment Required（需要付款）响应状态码，允许网络服务在常规网页交互过程中直接发起付款请求，无需跳转传统的结账结算流程。随着 AI 代理独立执行任务的能力日益增强，x402 为软件和机器之间提供了更加高效的点对点交易新模式，包括为获取数字服务访问权限或完成自动化任务进行支付。

Pi Network 已在 Pi 测试网上实现了对 x402 支付协议的支持，使应用程序、API、AI 代理和自动化服务能够通过程序化方式发起测试 Pi（Test-Pi）支付。Pi 提交的技术规范涵盖了 Pi 测试网与 Pi 主网，有关主网支持的更多详情将在上线前公布。

今天，OpenMind 演示了在 Pi 测试网上使用 x402 支付标准将其 RoboPay 平台与 Pi 支付进行集成的成果。该演示展示了开发者如何将 Pi 配置为支持的付款方式，以及自动化客户端如何请求机器人或服务操作、使用测试 Pi 支付并在付款完成后立即触发执行所需操作。

Pi 已将其针对 x402 支付的技术规范提交给 x402 基金会，目前正处于纳入 x402 官方规范标准的评审阶段。正如今天的演示所展现的，该集成功能已完全可用。

更多开发者平台新特性

除了今天峰会上演示的功能外，Pi 还推出了多项新特性，以全方位支持开发者在生态系统中构建应用。

改进终端用户入驻流程与 Pi 应用深度链接（Deep Linking）

Pi 显著改善了用户通过 PiNet 链接访问生态应用的入驻体验。当尚未安装 Pi 浏览器的用户接收并打开 PiNet 应用链接时，系统会引导他们通过 App Store 或 Google Play 下载 Pi 浏览器。在安装并打开 Pi 浏览器后，用户将被自动重定向至原本想要访问的 Pi 应用或特定页面。例如，如果一名 Pi Network 之外的用户受到先锋的邀请前往某款 Pi 应用体验游戏，他们在完成入驻后便可直接进入该游戏对局，无需再自行繁琐地手动寻找该游戏入口。

这种流畅的深度链接功能确保了网络外部用户在体验 Pi 应用时的连贯性，有效降低了开发者在拉新获客过程中的用户流失率，从而使开发者能够更轻松地将外部流量直接引入其应用之中。

通知中心

Pi 正式推出应用内“通知中心”（Notification Center），允许开发者从其 Pi 应用向用户发送生态系统通知，并方便用户在 Pi 生态系统内的一处集中查看所有通知。全体生态开发者现已可接入该功能，使其应用能够向用户推送相关通知、促进互动并提升长期用户留存率。这些通知将在 Pi 浏览器内呈现，而非直接作为手机系统级推送发送。

实现原生系统级推送通知是通知中心规划的下一步，届时将对开发者适用更严格、更具选择性的规则限制，以防止垃圾信息骚扰并确保善意合规使用。

在初期上线阶段，应用程序无需额外审批即可向最多 20 位用户发送通知。若开发者希望向更多用户推送通知，则需提交审批，这是在新功能推广初期用于防范垃圾信息的一项临时管控措施。

共筑未来

Pi 生态系统峰会第 1 天的日程充分彰显了 Pi 在持续优化开发者体验，以及强化支持生态系统发展的工具、基础设施与激励机制方面的不懈努力。这些举措通力协作，旨在帮助开发者构建实用应用、触达真实用户，并为先锋创造更多深入参与生态建设的机遇。

开发者可前往 Pi 开发者控制台探索并开启构建之旅，亦可访问 Pi 生态系统峰会落地页获取完整议程、后续重磅发布、技术演示及即将启动的黑客马拉松详情。
