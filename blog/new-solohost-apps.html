具有新的 SoloHost 应用程序：OpenClaw 和 Atlassian MCP 服务器

August 27, 2026

OpenClaw 和 Atlassian MCP Server 应用程序现已在 Pi Desktop 上的 SoloHost 中提供，扩大了有用的自托管软件的范围，用户可以更轻松地在自己的计算机上安装和运行。

这些应用程序与 Node 0.6.2 版本一起发布，展示了 SoloHost 如何支持不同的需求，从本地运行的 AI 代理到更专业的 AI 集成工作流程。

SoloHost 使用户能够通过 Pi Desktop 发现、评估、安装和运行自托管应用程序，而无需手动配置尽可能多的底层服务器、Docker 或其他技术基础设施。 OpenClaw 是一个本地 AI 代理，可以在本地模型或 ChatGPT 和 Claude 等外部模型上运行，而 Atlassian MCP Server 应用程序提供本地 MCP 服务器，用于将兼容的 AI 工具与 Jira 连接，帮助组织工作流程。

SoloHost 上的 OpenClaw：更简单、更包含的本地 AI

OpenClaw 是一个本地人工智能代理，可以在用户自己的计算机上运行并协助完成任务。在满足在本地 AI 模型上运行代理的硬件要求的计算机上，OpenClaw 可以让用户更好地控制其与数据和计算环境的交互方式，同时减少对支持任务的远程基础设施的依赖。如果代理使用云托管模型，例如 Claude 或 ChatGPT，则发送到该模型的请求仍会在模型提供商的基础设施上进行处理。在任一设置中，OpenClaw 的内存都是在用户计算机上本地创建和存储的。

当 OpenClaw 通过 SoloHost 运行时，它在一个容器内运行，该容器旨在限制其对更广泛计算机的默认访问。与 SoloHost 外部的直接安装（可能提供默认的更广泛的机器级访问（例如本地文件系统））相比，这会创建一个更加封闭的设置，减少对不相关的本地文件和系统资源的暴露，无论配置的模型是本地还是云。

此遏制不会消除所有风险或覆盖用户明确授予的权限。如果用户授权OpenClaw访问外部服务或资源，代理仍然可以在该授权范围内进行操作。 SoloHost 设置的好处更为具体：它限制对本地计算机其余部分的不必要的默认访问，同时允许用户授予特定任务所需的显式权限。

SoloHost 还通过打包应用程序及其所需环境以通过 Pi Desktop 自动使用来简化 OpenClaw 设置，从而减少用户需要处理的手动配置量。

将 OpenClaw 与已发布的 Hermes 本地 AI 代理一起添加，扩大了用户通过 Pi Desktop 可用的本地 AI 代理选项的范围。 OpenClaw 强调跨工具和消息传递渠道连接的个人助理，而 Hermes 则更强调持久记忆和从经验中学习技能。

SoloHost 上的 Atlassian MCP 服务器：将 AI 工作流程与 Jira 连接

SoloHost 上的 Atlassian MCP 服务器满足了专业人士（例如开发人员、产品团队和其他想要将 AI 工具集成到 Jira 工作流程中的人）的更专业需求。

为了使 AI 工具与 Jira 等服务进行交互，这两个系统需要一种通信方式。模型上下文协议 (MCP) 提供了一个框架，通过该框架，兼容的 AI 工具可以使用 MCP 服务器连接到外部系统（例如 Jira）。

Atlassian (Jira) 提供了自己的托管 MCP 选项，但团队在将其用于内部 AI 集成 Jira 工作流程时可能会遇到配额和可靠性限制。此 SoloHost 应用程序允许用户在本地运行不受配额或可靠性问题限制的自己的 MCP 服务器，从而解决了遇到这些限制的团队的需求。

具体来说，SoloHost 上的 Atlassian MCP 服务器允许用户自己的计算机或他们选择的机器在本地运行服务器。然后，兼容 MCP 的 AI 工具可以通过该本地服务器连接以与 Jira 配合使用。由于连接是基于 MCP 而不是某一特定的 AI 平台，因此它可以与不同的 MCP 兼容的 AI 工具（例如 Cursor、Claude Desktop 或 Claude Code、Codex）配合使用，使 Jira 上的工作流程组织更加自动化和智能。

为先驱者和 Pi 生态系统扩展 SoloHost 实用程序

OpenClaw 和 Atlassian MCP 服务器展示了 SoloHost 如何支持不同类型的自托管软件以满足不同的用户需求，从本地 AI 代理到更专业的开发人员实用程序。

这为先驱者提供了更多方式使用其计算机进行本地人工智能，并更轻松地访问其他自托管应用程序，进一步将 Pi 桌面和节点的实用性扩展到区块链基础设施之外。通过 SoloHost，人们可以从人工智能中受益，同时将更多数据和计算保留在自己的设备上，并减少对第三方远程基础设施的依赖。

同时，这两个应用程序演示了开发人员如何创建各种工具并将其引入 Pi 生态系统，并使它们可供 420,000 多个 Pi 节点运行者和更多桌面用户使用。

随着更多自托管应用程序的添加，SoloHost 可以继续扩大 Pi Desktop 作为实用实用程序平台的作用，同时为用户提供更多方式从他们已经运行的计算资源中受益。

SoloHost 仍处于测试阶段，并使用开放的、无需许可的发布者流程。用户应评估各个软件包并自行承担安装它们的风险。
