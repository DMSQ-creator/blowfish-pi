Pi 开放网络定于 2025 年 2 月 20 日上线！

2025-02-11

Pioneers、Pi Network将于以下时间正式过渡到主网开放网络时期上午 8:00（世界标准时间） 2025 年 2 月 20 日!

由于整个 Pi 社区过去六年的辛勤工作和承诺，Pi 社区正在朝着实现 Pi 迈出巨大的下一步想象世界上最具包容性的点对点生态系统和在线体验，由 Pi（Pi Network 的原生代币）推动

由于去年宣布的升级，我们已经实现了 1014 万次主网迁移，超过了最初的 1000 万次目标时间线更新，并且 Pi 已准备好开放其公用事业驱动的生态系统，我们现在超过 1900 万经过身份验证的先锋可以使用 Pi——一种具有实际功能和应用程序支持的加密货币。

发布当天，敬请关注有关开放网络的更多信息！现在，让我们回顾一下 Pi 的旅程、开放网络发布时的预期、开放网络条件的更新以及在此期间您可以如何准备！

我们的旅程

Pi Network 六年多的开放网络之旅建立在先锋、生态系统和社区推动的里程碑和深思熟虑的阶段之上。目前的主网第三阶段于 2021 年 12 月开始，推出封闭网络时期，这意味着主网已上线，但有防火墙阻止任何外部连接。这一时期为开放网络奠定了基础，为以下方面留出了时间：

  • 率先完成KYC并在主网上获取Pi；
  • 开发人员为 Pi 生态系统构建真正的应用程序和实用程序；和
  • 核心团队发布并改进各种 Pi 功能和实用程序。

继2022年3月早些时候，封闭网络也发布了新的挖矿奖励发行公式。下降指数模型平衡网络对增长、可访问性、寿命和稀缺性的需求，同时适当调整先锋者对网络贡献的奖励。

这宽限期于 2024 年 7 月 1 日颁布，旨在加速开放网络的进程，在为先锋者提供足够的时间通过 KYC 并有资格在主网上获得 Pi 之间取得平衡，同时为人们通过 KYC 并迁移到开放网络创造足够的激励和紧迫性。为了防止未经验证的 Pi 在超过 6 个月滚动 KYC 期限后在主网上获取 Pi，该策略有助于将 Pi 释放出来供其他先锋进行挖矿。

一直以来，在主网上获得 Pi 的先驱者都能够 与网络内的其他先锋进行 Pi 交易。例如，2024 年 Pi 节为期一周的活动促进了当地 Pi 商家和先锋购物者之间的 Pi 商品和服务交易，吸引了来自 160 个国家的 27,000 多名活跃卖家和 28,000 名测试商家，短短几天内就有超过 950,000 名先锋参与。 PiFest 展示了 Pi 用于本地商务集成的完整生态系统，通过 Map of Pi 连接商店发现、通过 Pi Wallet 进行支付、Pi 主网区块链上的交易以及 Fireside Forum 上的社交共享 - 所有这些都可以在不同的现有 Pi 应用程序中无缝工作

开放网络发布时有何期待

开放网络的推出为 Pi 层区块链带来了重要的新变化——外部连接，创造了一个 Pi 可以与外部系统安全连接的环境，为先锋和企业扩大了机会。

连接 Pi 与外部世界

向开放网络的过渡将实现主网区块链上的外部连接，从而使 Pi 能够与其他兼容的网络和系统进行交互。这意味着先锋将能够参与 Pi 生态系统之外的交易，从而扩大 Pi 的效用和影响范围。

在删除防火墙的开放网络启动后，任何人都可以在技术上将节点添加到主网区块链中，以运行协议和连接到网络。核心团队将逐步邀请先锋通过桌面节点 UI 将其节点从测试网过渡到主网，优先考虑那些具有强大历史贡献和可靠性得分的节点。节点排名数据将尽快公开。

网络参与的业务合规性要求

为了维护安全合规的生态系统，参与主网区块链活动需要对先锋进行 KYC（了解您的客户）验证，对企业进行 KYB（了解您的业务）验证。总体而言，Pi 旨在成为一个安全的 Web3 空间，先锋可以在其中与他们持有的 Pi 建立外部连接——KYB 的企业和合作伙伴与真正的 KYC 的先锋进行交互，反之亦然。

企业可以通过网页申请KYB验证这里。开放网络启动后，先锋可以在 Pi 网站上看到经过 KYB 验证的企业列表。

开放网络状况更新

开放网络日期的选择基于开放网络条件于 2023 年 12 月与整个社区共享。自 2024 年 12 月时间线更新以来，通过社区的努力，Pi Network 在完成开放网络条件方面的进展继续并加速。现在网络已经达到了开放网络所需的所有条件，因此是时候开放网络了！

下面让我们详细了解一下条件。

  • 条件 1：实现开放网络所需的所有技术、产品、业务和法律工作均已完成。
  • 条件2：
    • 19 百万先锋通过 Pi KYC 解决方案验证了自己的身份，包括条件中最初定义的完全和暂时的 KYC。这超出了原条件下1500万的要求。
    • 10.14 百万先锋已迁移到主网，超过了最初的 1000 万目标。
    • 我们已经达到了100主网或主网就绪应用程序，满足 100 个应用程序的目标，提供 Pi Network 在发布时在开放网络中蓬勃发展所需的充满活力、参与度和多样化的实用程序。
  • 条件3：会有开放网络的启动不会再出现延迟由于外部因素或不利的环境。

如果先驱者在开放网络启动之前或之后还没有进行 KYC 并迁移到主网，则应继续进行 KYC 并迁移到主网，并在 Pi 浏览器中使用 Pi 应用程序以支持生态系统开发和长期实用。同样，鼓励社区开发者开发、完善和推出符合 Pi Network 标准并为社区及其实用性做出贡献的应用程序。

开放网络时期先驱者和开发者应该做什么

随着开放网络阶段出现新的挑战，先锋和社区开发人员的贡献对于网络的实力和弹性至关重要。

以下是先锋积极参与的方式：

  1. 挖矿和贡献：继续挖矿，根据下降的指数发行模型和每月限额调整费率。
  2. 公用设施建筑：与 Pi Apps 互动，通过使用平台和 Pi 支持 Pi Network 和 Pi，并帮助扩展生态系统的效用。我们鼓励开发人员完善现有解决方案并创建新的解决方案，以满足 Pi 社区及其他社区的真正需求。
  3. 本地商业整合：鼓励店主继续接受 Pi，允许先锋参与点对点的商品和服务交易，使 Pi 在先锋的日常生活中继续发挥作用。
  4. KYC 和迁移：开放网络启动后，网络应继续进行 KYC 和迁移过程。如果您还没有这样做，请在开放网络期间尽快这样做。

对于开发人员：

  1. 改进您的主网应用程序：确保对您的应用程序进行改进，以实现满足用户的需求和愿望，并解决主网后出现的任何问题。
  2. 开发新的主网应用程序：构建 Pi 应用程序来为 Pi 生态系统做出贡献。了解更多这里. 

随着 Pi Network 进入开放网络时代，先锋、开发者和企业被邀请积极合作，推动创新，并确保 Pi Network 仍然是一个可持续、分布式和强大的社区。
