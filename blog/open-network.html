Pi 开放网络正式上线！

2025-02-19

先锋开放网络已经推出！这意味着 Pi 网络的外部连接现已可供世界各地的 Pi 社区使用。开放网络解锁了 Pi 蓬勃发展的生态系统、创新应用程序和广泛的点对点网络，以便与更广泛的区块链世界集成。开放网络是 Pi 使命的关键——创建一种包容性的、实用驱动的、广泛采用的、任何人都可以访问的加密货币。

正如 Pi Network 的开放网络中所讨论的日期公告今天的发布标志着 Pi Network 以及在过去六年中共同推动 Pi 前进的先驱者与更广阔的世界联系起来的一个重要里程碑。

启用外部连接后，先锋可以利用 Pi 公用事业支持的生态系统和应用程序与其他合规网络和系统进行交互。先驱者还能够参与 Pi 生态系统之外的交易，扩大 Pi 的现有效用和影响范围。

此外，先锋还可以通过以下方式查看和访问经过 KYB 验证的企业列表网页这有助于 Pioneers 识别那些已完成 Pi Network KYB 审核流程的企业。未列出？企业可以申请KYB验证这里. 

开放网络还支持与集中式交易所 (CEX) 和入口的集成，以提供获取 Pi 以在 Pi 生态系统中使用的其他方式、更多第三方服务以及节点更新等！

兴奋的？你应该是！请观看 Pi 两位创始人之一 Chengdiao Fan 的视频，并继续阅读，了解有关开放网络机会和现已推出的版本的更多信息。此外，准备好参加下周即将在 Pi 挖矿应用程序中举行的开放网络挑战赛，以了解和探索开放网络提供的第一手内容。
