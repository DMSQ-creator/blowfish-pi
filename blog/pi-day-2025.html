Pi Day 2025：全层级生态实用性拓展

2025-03-14

随着开放网络的推出和外部连接的启用，Pi Network 已进入新时代——一个那个将其蓬勃发展的生态系统连接到更广泛的区块链世界，并扩展其现实世界的功能. 

数以百万计的先锋正在使用 Pi，数以万计的企业正在将其集成到他们的服务中，并且构建了许多应用程序来满足社区和生态系统的需求并推动真正的参与——展示Pi的强度和稳定性不仅适用于 Pi 社区，还适用于更广泛的加密空间和互联网。

2025 年圆周率日庆祝 Pi 生态系统在各个层面上的扩展，无论是本地商业还是应用程序和平台级实用程序，同时利用全球 Pi 社区的力量和集体资源。 Pi 已经从先驱者投入的网络发展工作中获益，为网络基础设施、商业集成和公共设施建设做出了贡献。过去六年。先驱们已经并将继续认识到 Pi 的现实世界实用性、用例和可能性区块链技术以一种不墨守成规的方式提供，同时继续他们的旅程。

为了支持扩展 Pi 生态系统和 Pi 的整体实用性，Pi 今天发布了多项功能，伴随着全球 PiFest 活动的开始：

  • .pi 域名拍卖；
  • PiFest购物期开始；
  • 主网生态系统应用扩展；和
  • 主网生态系统 UI 改造。

.pi 域名拍卖：引入新的平台级实用程序

域名是任何在线生态系统的重要基础设施层。在开放网络后的第一个 Pi Day，Pi 生态系统的扩展首先是让 Pi 生态系统的参与者和贡献者有机会获得保护并进行定制.pi 域用于他们的业务、品牌、商店、内容、应用程序、网站、个人使用等，同时通过 .pi 域名拍卖为 Pi 加密货币提供平台级实用程序。该平台级实用程序利用 Pi 社区的集体资源以及开放网络提供的外部连接。

什么是 .pi 域？

传统的互联网域名充当唯一标识符和数字地址，使个人和企业能够建立一个可识别且可访问的在线状态，并促进轻松导航、品牌推广和用户参与跨越全球互联网基础设施。相似地，.pi域名充当 Pi 生态系统中的唯一数字标识符或虚拟店面，简化与基于 Pi 的网站、应用程序和服务的交互。

总体而言，.pi 域名的运营和组织通常遵循传统互联网域名行业数十年来的运作机制，例如所有权、转让、年度注册费等。但是，.pi 域名在两个方面存在显着差异：首先，它们专门在Web3环境，并且直接与 Pi 浏览器以及与此功能集成的第三方钱包和服务兼容，或者通过可在 Chrome 和 Safari 等旧浏览器中运行的 pinet.com 扩展程序兼容。其次，.pi 域名的收购过程包括拍卖和竞价使用区块链技术和 Pi 执行作为唯一的支付货币，并允许利用 Pi 区块链来确保 Pi 加密货币的透明度、安全性和直接效用。

.pi 域名与许多其他虚拟财产有何不同？

主要的区别因素是 .pi 域名的有形价值是得到全球超过 6000 万先锋、超过 1900 万经过身份验证的个人、超过 1200 万人在区块链上的关注和参与的支持，以及更多 - 通过区块链和第三方服务 - 除了全球数以万计的商家接受 Pi 之外，他们还准备进行交易。随着开放网络的推出，Pi 社区的参与度、参与度和实力已被全世界所见证。

另一个重要的区别是.pi 域名已经拥有清晰、直接且可衡量的现实用例, as well as practical applications now.商家可以轻松设置可识别的店面，先驱者可以使用简单的品牌域名访问这些店面。电子商务应用程序允许快速部署在线商店或博客，从而显着增强社区互动和商业。开发人员可以在个性化 .pi 域上构建和托管自定义应用程序，从而推动创新和技术发展。品牌受益于增强的身份、简化的用户采用以及生态系统内提高的可发现性。所有这些目前都在生态系统中可用。这与在没有任何人的情况下在空的 Web3 社交网络中购买虚拟财产不同，在这种情况下，财产的效用尚未实现，并且它们的用例现在和将来都不确定。

.pi 域名拍卖如何为 Pi 创建平台级实用程序？

作为提醒，一个平台级实用程序将 Pi 的集体资源转化为网络范围内的实用程序，以支持 Pi 作为所有先锋的货币。这与应用程序级实用程序不同，应用程序级实用程序仅限于特定的 Pi 应用程序上下文和功能。最新发布的平台级实用程序是Pi广告网络. 

同样，.pi 域名拍卖也是一个平台级实用程序，因为它直接利用 Pi 社区的集体资源——注意力、真实性和准备进行交易的大型社区——这使得 .pi 域名变得有用。

.pi 拍卖完全在 Pi 加密货币上运行——人们需要使用 Pi 来投标和购买具有现实世界意义和目的的东西。不接受或涉及其他货币或加密货币。通过出售 .pi 域名获得的所有 Pi 将专门用于 Pi 生态系统、开发者计划、活动和促进 Pi 的实用性。

拍卖会的运作和组织在很大程度上依赖于Pi 主网区块链，增加其用途，以及其特殊功能，例如可索赔余额对于先驱者和复用地址适合拥有 Pi 但尚未成为先锋的 CEX 用户。

拍卖参与规则

以下是 .pi 域名拍卖第一次迭代的运作方式：

  • 合格：整个 Pi 社区以及任何能够通过中心化交易所 (CEX) 获取 Pi 的个人。
  • 期间：拍卖于 2025 年 3 月 14 日 Pi 日开始，并将于 2025 年 6 月 28 日 Pi2day 结束。对于特定域名，如果在该域名拍卖结束前 24 小时内有新的出价，则该域名拍卖将延长。需要明确的是，这意味着特定域名的单独域名拍卖只有在该域名拍卖结束前 24 小时内没有新的出价时才会结束。
  • 规则及参与方式: 先锋可以通过访问参与https://domains.pinet.com在Pi浏览器上，它会引导人们到Pi钱包等相关产品来完成竞价。
    • 在拍卖界面中，输入您想要保护以供使用的域名；
    • 对域名进行出价（最低出价为10 Pi）；和
    • 出价最高者获胜并购买 .pi 域名供其独家使用，但未来可能需要缴纳年度注册费和维护费，类似于传统的互联网域名费用。
  • 投标方式：
    • 先驱者可以利用 Pi 区块链的成熟功能——可索赔的余额功能，允许先驱者以可逆的方式发送他们的 Pi 作为域名竞标。这意味着他们可以在拍卖结束前随时撤回之前出价的金额。
    • 拍卖会启动后不久，仅通过交易所拥有 Pi 的人也将能够参与拍卖。由于交易所不支持可索赔余额，因此流程会有所不同。在这些情况下，拍卖用户界面将为他们想要竞标的每个域名生成一个自定义 Pi 区块链地址（这些特殊地址将以字母“M”开头）。然后，这些人将能够将 Pi 发送到这些地址作为他们的出价。由于这些出价是作为标准付款实施的，因此任何退款只会在拍卖结束后处理。关于将域名转让给这些获奖者，他们需要建立标准 Pi 区块链帐户才能接收他们的 .pi 域名。想要利用 Pi 区块链的人可以通过正常的入职流程成为先锋圆周率移动应用程序.

笔记：公司保留自行决定以任何理由使任何域名拍卖或出价无效或取消的权利。例如，我们可能会从拍卖中排除已保留的域名和某些域名，以保留供官方或将来使用，例如 pi、pinetwork、coreteam、地图等。粗俗或冒犯性语言也将被排除。任何无效拍卖的参与者将随时通过可索赔余额功能或在 2025 年 6 月 28 日之后（对于非先锋者）收回他们作为质押出价提供的金额。需缴纳汽油费。拍卖参与者需要为每次添加 (0.01 Pi)、修改 (0.02 Pi) 或删除 (0.01 Pi) 出价支付 Gas 费。根据区块链的决定，实际中可能会适用额外或更高的汽油费。公司保留随时自行决定更改或修改这些规则的权利，无论是否通知参与者。

主网生态系统应用扩展

为了方便想要构建 Pi 应用程序的开发人员轻松入门，开始构建或部署已构建的 Pi 应用程序的应用程序设计得简单易用，方便开发人员使用。然而，让 Pi 应用程序在 Pi 浏览器的 Pi 生态系统界面上列出的标准要高得多，包括应用程序质量、应用程序功能的完整性、实用性评估以及遵守更严格的 Pi 生态系统政策和指南。之所以提出这个更高的标准，是因为 Pi 应用程序需要跨越一个最低门槛，才能从生态系统中先锋的流量中受益，反过来，这也可以激励开发人员构建更好的符合政策的应用程序，满足先锋及其需求。

尽管上面讨论了生态系统列表的更高标准，但该流程已得到改进，以使其更加简单且易于申请。为此，满足以下条件的开发人员主网应用程序部署要求现在可以直接前往开发者门户申请将其应用程序添加到主网生态系统接口，而无需等待被列入白名单。

以前，应用程序必须获得资格才能申请在 Pi 浏览器的 Pi 生态系统界面中列出。现在，这个预先批准步骤已被删除，这意味着符合条件的开发商不再需要等待批准即可申请。此更改简化了流程，并允许更多开发人员申请将其应用程序纳入主网生态系统接口。

此更新很重要，因为它：

  • 允许许多满足主网要求的开发者立即申请；
  • 将增加可见的主网应用程序数量Pi 生态系统内；和
  • 支持网络的效用和增长通过扩大主网应用程序的数量和质量。

Pi 已经拥有一组已上线的主网 Pi 应用程序，这为后续在主网生态系统接口上包含更多 Pi 应用程序和版本奠定了基础。主网应用程序列表不包括所有主网和主网就绪应用程序，因为选择受到质量、交付实用性以及对 Pi 生态系统政策和准则的遵守情况的限制。一些充当 Pi 主网应用程序目录的第三方 Pi 应用程序可能会显示更多甚至所有主网应用程序，因此先锋可以参考这些应用程序以获得更广泛的可用应用程序视图。

笔记：申请并不能保证您的应用程序将被纳入 -应用程序仍必须满足主网生态系统上市要求待批准。

改进的生态系统界面设计

生态系统界面设计改进了组织，帮助先锋更直观、更有效地导航社区应用程序，并通过更简洁的设计来改善用户体验。以前，每个应用程序都有“主网应用程序”或“不在 PiNet 上”等标签，这使得界面变得混乱。作为最近更新的一部分，这些标签已被替换为主网应用程序的“M”徽章、测试网应用程序的“T”徽章和“！”不在 PiNet 上的应用程序的徽章。当先锋点击应用程序了解更多详细信息时，他们还会在应用程序页面内看到这些徽章的说明。
