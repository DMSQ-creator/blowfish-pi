Pi生态峰会第2天：AI与生态系统

2026年11月18日

Pi Network 生态峰会今天（11 月 18 日）继续进行！继昨天的开发者平台发布和技术演示之后，第二天的重点是 Pi 的基础设施如何支持人工智能（AI）、人类协作以及现实世界的落地应用。

以下是今天视频节目的日程安排：

  • 开幕致辞：由 Pi 创始人 Nicolas Kokkalis 带来。

欢迎在太平洋标准时间上午 8:00 / 协调世界时下午 4:00 观看今天的峰会视频首播！

访问 Pi 生态峰会主页，即可查看所有峰会内容，包括视频演示、公告、技术演示、开发者对话以及黑客马拉松信息。

Pi DataLab：连接 AI 需求与 Pi 经过实名验证的人类网络

Pi Network 首次公开展示了 Pi DataLab，这是一个全新的“人机协同”平台，旨在将需要高质量人类输入的企业、AI 开发者和其他机构，与 Pi 全球已通过身份验证的用户网络连接起来。

随着 AI 系统的不断进步，训练、评估和提升其能力对人类生成的数据、反馈和判断的需求日益增长。通过 Pi DataLab，各类机构将能够创建并出资开展需要人类参与的项目，包括数据标注、排序、评估、具身智能（physical AI）数据以及其他依赖人类判断的任务。

该平台旨在允许客户定义任务、配置参与门槛和质量控制要求、将工作分配给合格的参与者，并监控和获取已完成的结果。

在参与者方面，先锋们将能够发现可用任务、查看说明和报酬、完成任务，并通过合格的贡献获得 Pi 作为奖励。该平台还将引入资格筛选和贡献者绩效评估等机制，以帮助维持所提交数据的质量，并建立贡献者声誉体系，为未来的任务机会提供参考。

Pi DataLab 建立在 Pi 现有协调大规模人类协作的经验之上。Pi 的 KYC 验证基础设施已经协调了由 100 多万名人类验证员完成的超过 5.26 亿次验证任务，这充分证明了该网络组织大规模分布式人类协作的能力。

今天的演示展示了 Pi DataLab 的核心工作流程，包括项目创建与管理、任务发现与完成，以及提交结果的处理。

更广泛地说，Pi DataLab 旨在向外部需求开放 Pi 的去中心化人类协作基础设施，在赋能人类参与 AI 数据创建与评估新形式的同时，为先锋们提供参与不断增长的 AI 经济的机会。通过 Pi DataLab 参与此类任务将获得代币报酬（包括 Pi 或在 Pi 上发行的代币），而不是像传统 Web2 平台那样使用法币结算。

AI 辅助 SoloHost 应用打包

在今天的节目中，Pi Network 展示了开发者如何利用 AI Skill 简化准备现有应用程序的过程，以便通过 SoloHost 发布供其他用户安装和使用。

SoloHost 赋能开发者将自托管应用程序引入 Pi Desktop，在 Pi 超过 42 万名节点运营商和其他 Pi Desktop 用户的生态系统内为其产品开辟新的分发渠道。

任何可以打包为 Docker 镜像的工作负载都可能在 SoloHost 中运行。这意味着开发者可以通过适当的配置对现有应用程序进行打包，以便在 SoloHost 环境中分发并触达 Pi Desktop 用户，并随着时间的推移有望触达更多的先锋。

Pi 最近在公开的 SoloHost GitHub 代码库中引入了一项新的 AI Skill，以简化应用打包流程。

开发者可以向兼容的 AI Agent（例如 Claude Code、Cursor 或 Codex）提供现有应用程序的公开 Docker 镜像。该 Agent 会询问应用程序应具备哪些功能，生成两个必需的配置文件（docker-compose.yml 和 config_options.yml），并对其进行验证。随后，开发者可以使用这些文件提交其应用程序以通过 SoloHost 上架。

今天的演示在实际操作中展示了这一过程，展示了 AI Agent 如何帮助开发者以更少的手动技术操作，为 SoloHost 准备好现有的应用程序。

开发者可以在 Pi 最近的技术更新中了解更多信息，或在 GitHub 上探索 SoloHost AI Skill。

CiDi Games：将 Pi 集成到游戏应用中

继第一天关于 CiDi Games 在 Pi 上构建经验的对话之后，今天的技术演示更深入地展示了其游戏平台如何集成 Pi 的开发者工具和基础设施。CiDi Games 的经验也彰显了 Pi 上为开发者提供的丰富工具，支持从构建和集成应用，到在 Pi 现有生态系统中实现支付、变现、用户获取和互动留存的整个应用生命周期。

该演示重点展示了 Pi 用户身份验证的使用、在受支持的游戏体验中进行交易的 Pi Payments（Pi 支付），以及用于将广告变现集成到应用中的 Pi Ads SDK。

综合来看，这些集成展示了开发者如何将 Pi Platform 的能力整合到自己的应用程序中，从而支持生态系统内的用户体验和商业模式。

其他全新开发者平台功能

Pi 发布了多项额外功能，以支持开发者在生态系统中构建应用程序。

更多编程语言支持：Pi 扩展了其开发者工具，以支持更广泛的编程语言和框架，包括 Laravel、Go、FastAPI、Node/Express 和 Ruby。这些新增支持让开发者能够更灵活地将 Pi 功能集成到使用他们已有技术构建的应用中。

统一文档：Pi 还发布了统一的开发者文档，将应用设置、身份验证、支付和测试资源整合到一处，使开发者能够更轻松地在 Pi 上构建和集成应用程序。

全新黑客马拉松将于明日启动

Pi 生态峰会的第二天重点展示了开发者如何利用 Pi 的基础设施创建涉及 AI、人类协作和实际效用的应用与服务。从连接人类贡献者与 AI 相关工作的 Pi DataLab 平台，到简化分发自托管 AI Agent 或访问分布式计算开发流程的 SoloHost，再到充分利用广泛 Pi 性能的 CiDi Games 技术集成，这些演示展示了 Pi 现有资源支持生态系统发展与实用价值的更多途径。

峰会将于明天（11 月 19 日）闭幕，届时将正式启动 Pi Next——Pi 全新的黑客马拉松，奖池高达 200,000 USDT，并设有高达 2000 万 Pi 的共享市场激励计划。开发者将有机会通过为 Pi 生态系统构建应用，将整个峰会期间重点展示的工具和功能付诸实践。

开发者可以访问 developers.minepi.com 开始探索，并访问 Pi 生态峰会主页了解完整的日程安排、技术演示、开发者资源和即将举行的黑客马拉松信息。敬请关注明天公布的完整黑客马拉松规则和说明（包括报名方式）！
