Pi Network Ventures 宣布首笔投资 OpenMind

October 29, 2025

Pi Network Ventures 对 OpenMind 进行了第一笔投资，该公司开发操作系统和开源协议，供机器人思考、学习和协作，就像机器人的 Android 一样。

对 OpenMind 的投资符合 Pi Network 和 Pi Network Ventures 的主要目标。 Pi Network 致力于利用区块链及其背后的资源来解决现实世界的问题。 Pi Network Ventures 致力于将世界上更多的产品转移到 Pi 上并提高 Pi 的效用。

OpenMind 的技术创建了一个共享智能层，使机器人能够在去中心化的生态系统中集体协作和学习。这补充了 Pi 对区块链和人工智能未来的愿景，其中去中心化基础设施支持开放创新和公平参与。

除了这项投资之外，Pi Network 和 OpenMind 还合作完成了一个概念验证项目，其中志愿者 Pi Node 操作员为 OpenMind 运行图像识别 AI 模型，从而证明 Pi Node 操作员可以为第三方组织运行计算。 OpenMind 的 AI 模型可以在 Pi Node 基础设施上运行的这一早期实验探索了 Pi 的全球节点网络支持去中心化 AI 训练和计算任务的能力，这是除了保护 Pi 账本之外的另一个 Pi Node 实用程序。这也是一个平台级实用程序，依赖于网络的集体资源，即超过 350,000 个活动节点的计算能力。

通过将未使用的计算能力转化为生产性工作，这项工作 (1) 使 AI 产品能够通过向 Pi 中的节点运行者支付费用，从 Pi 节点获取并满足其计算需求；(2) 允许 Pi 节点运行者选择从额外的节点实用程序中赚取 Pi，除了节点挖矿奖励之外。该 Pi 节点实用程序可以通过对 AI 基础设施层的这些计算和 AI 模型训练贡献，帮助进一步将 Pi 集成到 AI 经济中。

OpenMind 的战略契合 Pi Network Ventures 的目标

OpenMind 正在开发基础设施，使机器人和智能系统能够安全地与其环境以及彼此之间进行交互，且不依赖于单一供应商生态系统。其与硬件无关的 OM1 操作系统支持将智能机器集成到现实环境中。新推出的 FABRIC 协议允许机器验证身份、共享上下文以及跨物理和数字环境进行协调。您可以在此处了解有关 OpenMind 的更多信息。

对 OpenMind 的投资提供了一个潜在的机会，可以帮助 Pi Network 在人工智能驱动的世界中实现更广阔的区块链愿景。

Pi Network Ventures 参与 OpenMind 的融资轮反映了其致力于支持区块链和跨技术领域的强大初创企业和企业，这些初创企业和企业与 Pi Network 的方向一致。这补充了其三个核心投资目标：

关于人工智能驱动的世界中的区块链，Pi Network 认识到技术生产力（尤其是人工智能）引发了有关分配、生产以及人类劳动力和智力的作用的问题。在未来，生产力和交易将越来越多地由代表人类的人工智能代理来执行，这些代理的支付方式的集成和可访问性是一个重要特征。

使这些代理能够在现实环境中自主运行和有效协调的基础设施至关重要。

OpenMind 致力于构建一个共享智能层，支持从自主物流到工业自动化等跨领域的机器协作，并为可互操作的人工智能应用层的进步做出贡献。这一层位于高性能人工智能基础设施和现实世界生产之间，在 Pi 看来，增强这一层的能力对于确保人工智能的好处公平地惠及人类参与者至关重要。

OpenMind 正在开发的架构可能代表了开发以开放和适应性强的方式扩展智能系统所需的协调基础设施的一种途径。反过来，此类系统可能会为支持区块链的身份、访问、身份验证、支付或激励机制层（Pi 拥有现有基础设施和生态系统活动的类别）创造机会。

在此背景下，Pi Network Ventures 对 OpenMind 的投资支持了更广泛的目标，即在人工智能日益占主导地位的世界中准备与现实世界的 Pi 实用程序集成的技术和生态系统环境。

概念验证：构建去中心化计算实用程序

允许 Pi 节点运营商为 OpenMind 运行计算的举措代表了探索人工智能训练的去中心化计算、利用 Pi 全球节点网络的分布式能力的早期阶段。

Pi 的共识算法被设计为节能的，这意味着仅保护账本并不需要 Pi 超过 350,000 个节点的整个网络的全部计算能力（尽管它受益于这些节点的去中心化方面）。因此，Pi 节点保留了大量未使用的计算能力。这种集体计算能力是一种宝贵的资源，可以在节点层之上启用新的实用程序，例如去中心化云计算。

随着人工智能不断需要越来越多的计算资源，利用全球 Web3 网络的闲置容量可以帮助满足这些需求，同时为 Pi 提供现实世界的实用性。通过使节点能够执行与 AI 相关的计算，Pi 为其生态系统内的实用和经济活动开辟了新的垂直领域的潜力。那些需要计算能力进行 AI 模型训练的人可以向 Pi 中的节点运营商支付额外容量的费用，从而创建一个比传统集中式平台更容易访问且更具成本效益的去中心化云计算市场。

通过将 Pi 的去中心化劳动力网络与其计算层相结合，这一愿景可以进一步扩展——允许人工智能模型开发人员从同一生态系统内获取人类反馈和计算能力。在此过程中，Pi 旨在打造一个独立的环境，让人们贡献劳动、提供计算并获得 Pi 作为回报，通过去中心化参与推动下一波人工智能发展。

注：Pi Network Ventures 投资旨在在更广泛的时间范围内为那些被认为最有能力在世界范围内创造价值的人提供资本和战略价值，并帮助提供在全球范围内使用 Pi 的其他方式。投资流程旨在反映传统硅谷风险投资公司在采购、选择、审查流程等方面的做法，旨在识别和支持高影响力和颠覆性的初创企业和企业。考虑到这一点，Pi Network Ventures 的参与应严格理解为投资，而不是投资接受者成功的保证。风险投资实践旨在支持变革性的初创企业和创新——这些初创企业和创新是由每个团队的实力和执行力驱动的——重点关注那些成功上限高于潜在风险的公司。

• 增加 Pi 的实用性，

• 使世界上更多的生产能够进入 Pi 网络，以及

• 将 Pi 引入现实世界的用例。
