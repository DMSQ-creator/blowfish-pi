Pi 节点 0.5.4 版本更新

2025-11-06

The Pi Node has been updated to version 0.5.4, introducing several improvements to Node performance and the user experience on the Pi Desktop application. The release focuses on improving reliability, accessibility, Node rewards calculations and responding to issues raised by the Pioneer community.

  • Community-Reported Fixes: Version 0.5.4 resolves several issues reported by community Node operators in 0.5.3, including problems affecting Node mining rewards, automatic updates, and block container creation. These fixes enhance Node reliability and ensure smoother operation across various environments.
  • New Open Port Verification Mechanism: The Node now includes an improved system for tracking open ports on Pioneers’ Nodes. This update allows for more reliable and secure Node bonus calculations. It’s also an essential step towards the larger goal of enabling the migration of Node mining rewards.  
  • Enabling External Links: Pi Desktop* now supports opening approved external links, enabling access to blog posts, resources, and updates that are linked from the mining app and Pi App Studio. External redirects were previously disabled. This feature would help avoid breakdowns in user experience with the Node when encountering external links.
  • Easier Access to Pi App Studio: As announced in the recent update, Pi App Studio is now directly accessible from the top navigation bar in Pi Desktop, positioned alongside the Pi mining app and Node. This replaces its previous location within the Utilities tab in the Pi mining app.
  • Fixed App Studio Preview: An App Studio display issue where deployed apps were not displaying previews correctly has been resolved.

*Reminder: the Pi Node application has been renamed “Pi Desktop” because it allows Pioneers to access the Node, mining app, and Pi App Studio.

These updates continue to strengthen the Pi Node’s role as both a core part of the blockchain and a platform for ecosystem utilities. 

Following last week’s announcement of the initiative allowing Pi Node operators to run computations for third-parties, Pi Network will later release a case study sharing the results of this proof-of-concept project with OpenMind. The project explores the capability of Pi’s global network of Nodes to support decentralized AI training and computing tasks.
