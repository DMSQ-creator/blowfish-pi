Pi2Day 2025：推出 AI 倡议以扩展下一代应用

2025-06-27

先锋们，2025 年 Pi2Day 快乐！

今天，Pi 发布了两大功能：(1) 一个人工智能应用平台，旨在基于区块链和人工智能技术，解决随着人工智能进步，世界面临的问题，并扩大先锋者为生态系统中的 Pi 应用程序和实用程序做出贡献、参与和支持的机会； (2) 另一个平台级实用程序，允许先锋和企业通过质押机制支持 Pi 应用程序和实用程序。

此外，还发布了各种技术和产品更新以及新的 Pi2Day 生态系统挑战赛，先锋者将通过新版本和 Pi 生态系统功能来获得数字奖品。

在讨论 Pi2Day 的发布之前，让我们更深入地探讨本周早些时候向社区提出的有关人工智能、区块链和 Pi 网络的问题：“GenAI 与 Pi 网络有何关系？”

Pi 针对人工智能驱动世界的解决方案

任何技术（包括区块链）的最终效用都在于解决人类的根本问题。今天，我们正处于人工智能基础设施突破的关键时刻。然而，世界面临着以下尚未解决的问题。

Pi相信世界可以使用人工智能和区块链技术来解决这些问题。 Pi 认为，这两种技术之间的交叉点超出了对“去中心化人工智能应用”的典型理解，“去中心化人工智能应用”通常狭隘地关注去中心化数据、计算、治理和人工智能问责制的所有权。虽然这些方面仍然很重要，但 Pi Network 看到了区块链更基本的效用：用于社会分配和再分配的可扩展且可访问的解决方案。因此，Pi 强调了区块链和人工智能更广阔的愿景：通过区块链对人工智能创造的生产进行宏观层面的去中心化。通过区块链技术，人工智能的生产应该在加密网络中公平、包容地分配给人类，解决围绕人类福祉、经济公平以及人类智能在人工智能驱动的未来中的可持续作用的核心挑战。

实现这一愿景需要一些关键组成部分。首先，必须建立真实性，准确地区分真人与人工智能实体，以确保分发到​​真人。其次，需要有一个蓬勃发展且多产的人工智能应用层，将先进的人工智能基础设施与实际的现实生产联系起来；这意味着创作者能够轻松构建与区块链集成的创新人工智能驱动应用程序。第三，活跃的社交网络对于广泛分发这些应用程序、促进其被许多人实际使用并实现可持续的商业模式至关重要。最后，利用区块链的问责制和透明权利管理的内在特征，确保这些应用程序产生的产品直接、公平地惠及生态系统内的真正人类用户。

Pi Network 具有独特的优势，能够有效应对这些挑战，并且已经建立了实现这一目标所需的关键基础要素。为了保证真实性，Pi 开发了原生 KYC 解决方案，要求每个账户在进入 Pi 主网之前都必须通过身份验证，确保社区的高度人性化。目前，经过 Pi KYC 处理身份验证后，已有超过 1370 万人迁移到 Pi 主网。为了满足大型社交网络的需求，Pi 拥有全球最大的加密社交网络之一，在 200 多个国家和地区拥有超过 6000 万活跃会员。

出于区块链问责性和透明性的特点，首创作为一个区块链项目，在其挖矿机制中采用了公平的设计原则，以确保其网络的收益被社区广泛获取和包容性共享。最后，为了促进人工智能应用层的蓬勃发展和丰富，Pi 今天正式发布了由 GenAI 功能支持的 Pi App Studio，使创作者（而不仅仅是工程师）能够轻松创建和启动创新的、区块链集成的人工智能应用程序。除了今天发布的生态系统目录质押功能之外，现有的 Pi 产品（例如 Pi Ad Network、.pi 域名和 Pi 钱包）支持 Pi App Studio，可进一步实现这些应用程序的实际使用，并帮助在 Pi 生态系统内建立可持续的商业模式。

[H2]Pi App Studio：AI时代应用创建新模式

Pi App Studio 是实现许多技术人员共同愿景的一次尝试：一个任何人都可以使用人类语言创建和运行应用程序的世界，而无需技术背景。除了 GenAI 功能之外，Pi App Studio 与其他当前 GenAI 氛围编程平台的区别的重要方面是其引导式应用程序创建工作流程、访问数百万潜在创建者以及这些生成的应用程序的用户，这提供了高效的迭代过程，我们认为这对于真正的产品构建是必要的。因此，Pi App Studio 与其他现有的 Pi 生态系统组件一起，不仅可以创建和运行应用程序，还可以创建功能性在线产品。

对引导式工作流程的需求是基于 Pi 的洞察，即并非每个人都具备构建产品的专业知识。为了让任何人都能构建产品，仅仅解决工程进入壁垒还不够——这只是问题的一半。随着人工智能的兴起，应用程序创建的限制因素已经从技术能力转向创造力和分发，即构建什么以及在哪里部署。

引导式工作流程对于帮助普通人发挥其领域知识、专业知识和才能并将其整合到造福他人的实际产品中至关重要。打个比方，如果你把一块空白的画布和画笔交给一个从来没有学过画画的人，尽管他有必要的工具，但他仍然可能画不出一幅好画。要创作出一幅融合了个人独特视角和创造力的美丽画作，需要有一个教育和指导的工作流程，为他们创作作品提供必要的结构。

新产品需要用户测试并提供反馈，从而可以对功能和商业模式进行进一步迭代和改进，以确保产品的可持续性。这就是 Pi Network 现有的社交网络和生态系统组件可以为应用程序创建者提供的功能。应用程序创建者可以从现有先锋对其产品的真实反馈中受益，从而使应用程序创建者能够改进他们的产品，并借助当前 Pi 产品（例如 Pi 广告网络、.pi 域名、Pi 钱包等）在 Pi 中创建商业模式。反过来，Pi 生态系统也受益于创建者的可扩展应用程序创建、实用程序扩展和社区参与。

这使得更广泛的人能够以去中心化的方式进行更多的迭代和尝试，以比 Web2 时代创建应用程序所需的工程成本更便宜的方式创建应用程序。

通过将人工智能与 Pi Network 的工具和集体资源相结合，Pi App Studio 旨在帮助人们将他们所知道的知识转化为其他人可以使用并从中受益的实际应用程序。

今天发布的版本包括两个选项。首先是一个工作流程，使先锋能够创建通过人工智能训练和自动化的特定主题聊天机器人，利用创建者的领域知识和专业知识来完善 GenAI 聊天机器人，更好地回答用户关于特定主题的问题并定制用户体验。虽然通用聊天机器人可以提供答案，但利用个人创作者的领域专业知识和创造力的精致人工智能聊天机器人可以提供更量身定制的响应和多样化的用户体验——有可能超越传统的聊天机器人界面。毕竟，谁说问答互动必须始终采用“聊天机器人”的形式？如果它们以分步向导、交互式测验、推荐引擎，甚至是像神奇 8 球这样有趣的东西出现，会怎么样？此外，除了精通技术和人工智能的受众之外，大多数主流用户尚未依赖通用 GenAI 聊天机器人来满足日常信息需求。为了加速大规模采用并提高人类生产力，更具针对性、针对特定主题的人工智能应用程序（融入了个人创作者的专业知识和创造力）可以为更广泛的公众参与人工智能提供更直观、更有效的切入点。

第二个选项是 Beta 版的开放平台，允许先驱者创建他们已经想到的任何类型的应用程序，而无需编写代码。先驱者可以使用人类语言（而不是代码）来创建他们想要构建和拥有的应用程序。因为这仍处于测试阶段，请注意访问可能受到限制，并且用户体验仍在完善中。

在当前平台之上创建的更多工作流程可以指导更多应用类型的创建。

创建者的聊天机器人、其他类型的应用程序或自定义应用程序完成后，Pi App Studio 可以帮助应用程序创建者使用 AI 自动将其应用程序部署到云服务器，并将自己的应用程序启动到 Pi 生态系统。根据用户反馈，创建者迭代地确定哪些内容能引起先锋的共鸣，通过类似于创建流程的过程对其应用程序进行更改，然后重新部署并重新发布其应用程序到社区 - 所有这些都通过 Pi App Studio 进行，无需编写代码。

为了像任何其他产品一样增加用户入门和参与度，Pi App Studio 创建者还可以利用 Pi 的其他产品（例如 Fireside Forum 和 Pi Chats）将他们的应用程序与更广泛的 Pioneers 社区联系起来。为了在 Pi 中创建商业模式，创建者可以稍后利用 Pi Ad Network，Pi 应用程序所有者目前正在其中赚取收入，并且创建者当前可以为其应用程序竞标 .pi 域名，以便于访问。

Pi Network 的独特优势（例如，使用和拥有 Pi 加密货币的数千万经过身份验证的 Pi 先锋的潜在参与度）激励应用程序创建者优先考虑质量、增长和准确性。应用程序的性能越好，人们使用它的可能性就越大。

因此，通过 Pi App Studio 创建应用程序意味着您能够拥有并运营完全围绕您的知识和想法构建的业务和产品，这是通过使用人工智能并得到 Pi 区块链生态系统的支持而实现的。

生态系统目录质押：使用 Pi 支持生态系统中的 Pi 应用程序和实用程序

Ecosystem Directory Stake 是一种新的平台级实用程序，它为先锋和企业引入了一种去中心化的方式，以积极支持和促进 Pi 应用程序和实用程序在生态系统界面中的排名。该功能可通过 Pi 浏览器访问，并于 6 月 28 日开始推出，使先锋和企业能够将其 Pi 质押在主网区块链上，用于他们选择的应用程序，直接提升该应用程序在生态系统中的排名。除了 Pi 在质押方面的效用之外，这还旨在提高更高质量的应用程序的曝光度并提供有意义的社区参与。 2025 年 6 月 29 日更新：质押是先锋和企业支持他们在生态系统界面中使用和享受的应用程序的一种可选方式。请注意，质押在协议级别上没有 Pi 奖励，因为网络通过此质押功能将一个 Pi 应用程序推广到另一个应用程序是没有意义的。特定 Pi 应用程序或服务的第三方开发者是否想要提供任何激励（无论是应用程序功能和质量、用户体验、应用内奖励、促销等形式），以鼓励先锋为其应用程序或服务质押 Pi 并提高其在生态系统中的排名，这取决于他们。质押期限结束后，原始质押金额将返还给用户。

从战略上讲，这种机制是一个平台级实用程序，利用 Pi 的集体注意力资源，不仅通过 Pi 社区的众包力量支持应用程序和实用程序，而且与典型的 Web2 应用程序排名系统区分开来，后者主要由创建信息孤岛的严格算法或广告公司控制。该功能促进了旨在提高质量并分散整个 Pi 网络影响力的循环。

第三方入口匝道和入口匝道服务的集成

Pi 钱包现在集成了 Onramper，这是一个经过 KYB 验证的第三方入口聚合器，可简化 Pioneers 的入口服务。先驱者可以通过 Pi 钱包访问 Onramper，选择他们喜欢的符合 KYB 的入口匝道服务，但须遵守入口匝道的区域可用性和其他限制。这种集成为更多先锋提供了参与主网生态系统的简化方式。无障碍功能将于下周逐步推出。

主网迁移和 KYC 更新：解锁超过 500,000 个额外先锋

主网迁移和 KYC 的最新更新使更多先锋有资格进行迁移。除了自开放网络推出以来已迁移超过 300 万个先锋的正常迁移流程之外，这些更新还解锁了超过 500,000 个之前无法继续进行的先锋。

一项 KYC 更新专门帮助解除了某些地区先锋面临的独特挑战，这些挑战需要进一步检查其暂定 KYC 状态，以达到最终 KYC 状态并允许他们继续进行主网迁移过程。

通过与其他区块链流量分离的专用区块链 API 服务器，迁移过程也得到了改进。这有助于提高迁移稳定性和吞吐量。

先驱者可能仍需要完成特定操作才能进行迁移。确切的时间将取决于每个人何时完成这些步骤，但他们不再受到之前阻止其迁移的系统限制的限制。

.pi 域名拍卖扩展

正如之前博客中所讨论的，.pi 域名旨在成为功能性 Web3 标识符——Pi 支持的应用程序、服务和店面的锚点。由于 Pi App Studio 的发布，更多的先锋将能够创建和运行自己的应用程序，因此需要与他们的应用程序一起使用的域名，因此 .pi 域名拍卖截止日期延长至 2025 年 9 月 30 日，以便为先锋提供更多时间来创新和构建功能应​​用程序，并为其应用程序竞标所需的 .pi 域名。
