Pi2Day 2026：通过计算、人工智能和身份推进实用程序和外部访问

June 28, 2026

先锋们，Pi2Day 快乐！

Pi Network 正在推出新版本来庆祝 Pi2Day，这些新版本既提高了 Pi 在 Pi 生态系统中的实用性，又将其扩展到 Pi 平台之外，扩展到外部世界。今天的三个关键版本将 Pi 的服务扩展到 Pi 生态系统之外的企业和开发人员，同时邀请他们加入 Pi Network 并利用 Pi 的独特优势和资源。

  • SoloHost 是 Pi Desktop 上的一个开放式、无需许可的框架，开发人员可以在其中构建和列出有助于运行本地 AI 以及很快的分布式计算用例的应用程序。用户可以在自己的计算机上发现并运行这些应用程序，并通过移动设备上的 Pi 浏览器与相应的应用程序交互。
  • Pi Sign-in 使先锋能够使用其 Pi 帐户登录受支持的第三方网站和应用程序，这可以在 Pi 浏览器之外受益于 Pi 的网络规模和经过验证的身份资源。这有助于扩大 Pi 在更广泛的互联网和第三方环境中的影响力，同时支持与 Pi 生态系统的更轻松的集成和更顺畅的连接。
  • PiVerify 使 Pi 的真人验证功能可供需要对其用户进行 KYC 和身份验证的第三方客户使用。这为外部平台提供了一种减少虚假或重复帐户并支持与合规性相关的工作流程的方法，同时验证其用户有助于通过 Pi 的 KYC 解决方案扩大经过验证的个人池。客户还可以用 Pi 付费来使用 PiVerify 服务，这增加了 Pi 的效用。

这些版本共同推进了 Pi 在计算、人工智能和身份方面的实用性。通过首先为外部第三方提供有用的服务和资源，例如 Pi 的区块链基础设施、身份验证和大型全球参与网络，Pi 提供了多种独特的激励措施，不仅可以使用 Pi 的服务，还可以加入 Pi 的现有生态系统并为之做出贡献。

这在人工智能时代尤其重要。

随着人工智能不断改变人们、应用程序和企业使用数字基础设施的方式，计算和身份正成为可以运行、扩展和服务真实用户的应用程序的更加重要的基础。更多的应用程序需要访问计算资源，人们在受益于人工智能的同时对个人数据隐私变得更加敏感，对本地运行的人工智能应用程序和本地设备连接的需求不断增长，许多数字服务需要更好的方法来验证真实的人类参与。

除了这些产品更新之外，Pi2Day 生态系统探索邀请社区了解有关新版本的更多信息、测试功能、参加测验并赢得应用内徽章来炫耀！

SoloHost Beta 发布：Pi 桌面、自托管应用程序和分布式计算

Pi 推出了 SoloHost，这是 Pi Desktop 中的一个新框架，使第三方开发人员能够在开放、无需许可的发布者流程中构建和列出自己的应用程序和节点实用程序。用户可以在自己的计算机上发现、评估、安装和运行这些自托管应用程序。

适合 SoloHost 的应用程序通常包括：

  • 供个人使用的应用程序，例如本地运行的人工智能代理；和
  • （正在进行中）利用可用节点资源的分布式计算应用程序。

此版本将现有的 Pi Node 和 Pi Desktop 环境转变为实用程序创建的更实用的基础。此更新不再仅将节点视为支持 Pi 区块链的基础设施，而是为先锋提供了将计算机用于应用程序、人工智能实用程序、分布式计算和其他基于计算的用例的新方法。

通过构建现有的 Pi Node 和 Pi Desktop 环境，SoloHost 降低了运行自托管软件的障碍。该产品不需要用户手动配置服务器、Docker 环境或其他技术基础设施，而是通过 Pi Desktop 简化了对本地应用程序的访问。它还允许 Pioneer 的计算机充当自己的服务器，这样他们就可以通过 Pi 浏览器中的 SoloHost 应用程序从手机访问在桌面上本地运行的受支持应用程序。

通过这种设置，人们可以从人工智能中受益，同时将数据保存在自己的设备上，而不必与第三方远程服务器共享。

请注意，SoloHost 目前处于早期测试阶段，可用性将逐步推出。随着产品的改进，体验和功能可能会发生显着变化。

SoloHost 上发布的一款应用程序是 Hermes，这是一款开源本地 AI 代理，可以在用户自己的计算机上运行和存储其所有数据。 Hermes 演示了本地人工智能代理如何帮助用户完成任务、回答问题或处理信息，同时将实际计算和数据保留在用户设备上。在本地运行可以更好地控制数据和隐私，减少对支持任务的外部基础设施和云服务的依赖，并使用户能够直接从他们已有的计算能力中受益。

分布式计算是SoloHost的另一个核心组件。随着人工智能模型、代理和应用程序的发展，对计算资源的需求不断增加，而世界上大部分可用的计算能力仍然分散在各个设备上。 Pi 的 Node 网络定位不同：它已经是一个由超过 420,000 台 Pioneer 操作的计算机组成的大型分布式网络，当 Node 操作员选择加入时，这些计算机可以进行协调以完成有用的工作。

通过帮助合适的应用程序访问可用的 Node 资源，SoloHost 可以将 Pi Node 转变为 AI 相关应用程序和其他计算密集型工作负载的实用计算层，同时为先锋提供了一种通过他们已经运行的计算机从这些新生产流程中受益并直接做出贡献的方法。

一个例子是即将推出的分布式计算应用程序，它将允许排名前 100 名的节点运营商贡献可用的计算资源来完成人工智能任务。该应用程序建立在之前的概念验证项目之上，并进一步自动化、扩展和完善功能，使其成为一个真正的应用程序，旨在为第三方客户提供生产级实用程序。参与节点可以由 Pi 中的第三方客户端进行补偿，进一步展示 Pi 节点如何通过将可用计算能力转化为实际应用程序的资源来支持 Pi 超越区块链基础设施的效用。该应用程序将在 Pi2Day 之后不久在 SoloHost 中发布。

对于开发者和发布者来说，SoloHost 被设计为基于节点的实用程序的开放式、无需许可的发布者流程。任何拥有 Pi 帐户的开发人员都可以创建自托管应用程序并将其提交上市，对包进行结构检查，但没有传统的预发布审核管道。这使得该目录更接近于一个开放的开发者平台，而不是一个精心策划的应用程序商店，以鼓励参与，特别是来自人工智能构建者社区的参与。用户应自行评估每个应用程序或软件包并自行承担安装风险。

这为开发人员提供了一种新的方式来接触超过 420,000 个已经运行 Pi Desktop 并可以在自己的计算机上运行应用程序的 Pi Node 操作员，并进入数以百万计的更大社区，其中更多人可能会选择安装 Pi Desktop 以从有用的本地运行的 AI 代理中受益。

  • 构建本地运行的AI 代理或自托管应用程序？探索将其列在SoloHost 上，以便需要运行自己的本地AI 来保护数据隐私的Pi 节点运营商和先驱者可以通过Pi Desktop 发现、下载和运行它。
  • 需要适合的非敏感工作负载的计算能力？Pi 将很快发布一个生产用例，以向开发人员展示构建分布式计算实用程序的能力，该实用程序将其工作负载与参与的 Pi 节点连接起来。

SoloHost 上的开发人员还可以受益于 Pi 的生态系统优势，包括分发、通过 Pi KYC 进行身份验证、Pi 帐户登录、Pi 钱包、Pi 浏览器、节点设置和 Docker 熟悉度。

随着自托管应用程序和基于节点的实用程序成为 Pi 桌面和更广泛的生态系统体验的一部分，它们还需要连接用户、设备、发布者和服务的方法。应用程序需要简单的方法来验证 Pi 用户的身份，启用用户的本地设备连接，支持跨生态系统体验的访问，并建立在可信参与的基础上。这就是 Pi 登录的用武之地。

Pi 登录：通过 Pi 的验证身份连接互联网

Pi 登录允许受支持的第三方网站和应用程序提供 Pi 作为登录或注册选项。随着 Pi 扩展到 Pi 生态系统之外的更多应用程序和实用程序，这一点变得越来越重要。

对于用户来说，这意味着他们可以使用 Pi 帐户访问支持的服务，而不是为每个应用程序创建新帐户或密码。根据体验，用户可以通过扫描二维码或从移动浏览器移至 Pi 浏览器来授权通过 Pi 进行访问。从 Pi 共享到应用程序的任何信息都需要用户的明确同意。今天发布的是 Pi Sign-in 的初始版本，该版本将随着时间的推移进行迭代和改进。

为什么第三方服务或网站想要集成 Pi Sign-in？ Pi Sign-in 创建了一种更简单的方式将他们与 Pi 的庞大用户群联系起来，并将 Pi 用户带入他们自己的产品体验中。它还使 Pi 在更多第三方环境中出现，同时为这些服务提供了一种方式，可以利用除用户流量之外的 Pi Network 的额外优势和资源。

这对于 SoloHost 的发布尤其重要。应用程序可能在先锋的桌面上本地运行，但仍然需要支持用户从其另一个本地设备（例如手机）进行访问，以便远程访问本地运行的人工智能代理并从中受益。 Pi Sign-in 通过用户的 Pi 帐户对其他本地设备进行身份验证，同时还可以与其他 Pi 生态系统服务（例如钱包）进行交互。使用 Pi 登录只是证明设备是您的，因此只有您可以打开应用程序。 Pi 登录有助于将访问权限锁定到正确的 Pi 用户，因此计算机上本地运行的 AI 应用程序仍然可以通过计算机本身之外的其他设备使用和访问，而无需用户进行技术工作来设置自己的设备网络。这使得本地运行的人工智能的体验与第三方人工智能应用程序提供的体验相当，而且不会暴露个人数据。

最终，Pi Sign-in 还可以帮助开发人员构建利用 Pi 更广泛的生态系统优势的体验，包括其 KYC 支持的经过验证的人力资源。

PiVerify：真人 KYC 和第三方身份验证

Pi 正在推出 PiVerify，这是一项 KYC 和身份验证服务，使第三方客户可以使用 Pi 的真人验证功能。借助 PiVerify，外部平台可以使用 Pi 现有的 KYC 验证解决方案来验证其用户，减少虚假或重复帐户，并支持与合规性相关的身份工作流程。

PiVerify 在 Pi Network 首个开放网络周年纪念日首次推出，它建立在 Pi 的 AI + 人类 KYC 模型之上，该模型已验证了 200 多个国家和地区超过 18+ 百万的先锋。该系统将人工智能自动检查与人工验证相结合，支持全球范围内的真人验证。虽然 KYC 提供商已经存在，但 Pi 的方法在几个方面有所不同：全球地理覆盖；可扩展性；人工智能和人类混合验证模型；以及解决方案的完整性——Pi KYC 不仅解决身份验证问题，还解决合规性制裁检查、人工验证器工作流程、跨网络比较以及对不同监管格式的支持。

通过向第三方提供此基础设施，PiVerify 将 Pi 验证身份技术和资源的实用性扩展到 Pi 自己的应用程序和服务之外。随着越来越多的服务使用 PiVerify，通过 Pi 系统验证的人数将超过 1800 万 KYC 验证的先锋，进一步加强 Pi 生态系统背后的经过验证的人类基础。第三方客户也可以用 Pi 付费来使用 PiVerify 服务，从而扩展了 Pi 本身的效用。

对于企业和平台来说，需求很简单：许多数字服务需要知道用户是否是真实的人。任何有意义的交易都需要经过验证的身份，尤其是在现实世界的经济中。

金融科技平台、交易所、Web3 服务、信任驱动的应用程序以及人工智能或数据平台都面临着虚假账户、重复用户、欺诈、垃圾邮件和 Sybil 滥用的风险。 PiVerify 旨在帮助这些服务将真人验证添加到其入职、重新验证、访问、参与、支付或数据工作流程中。

PiVerify 可以支持身份验证服务，例如文档检查、活性验证、制裁和 AML 筛选支持以及重复检测。这些功能可以帮助第三方客户提高信任度并减少滥用，同时为他们提供灵活的方式与 PiVerify 集成，例如将验证流程直接嵌入到他们自己的产品中。

Pi2Day 2026 反映了 Pi 的效用如何通过基础设施和参与持续增长。 Pi 桌面和节点可以支持新的本地应用程序和计算用例； Pi Sign-in 可以帮助连接用户、设备和服务之间的这些体验； PiVerify可以将Pi的真人验证能力扩展到第三方客户端。
