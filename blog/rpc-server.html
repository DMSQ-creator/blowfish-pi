Pi Testnet RPC 服务器发布：实现可扩展的智能合约开发

April 8, 2026

Pi Network 在测试网上发布了远程过程调用（RPC）服务器！

这是一个重要的基础设施里程碑，支持 Pi 生态系统内智能合约的开发、测试和未来部署。

该版本建立在 2026 年 Pi Day 宣布的节点和协议升级的基础上，其中 Pi 的主网区块链升级到协议 20，为智能合约功能奠定了基础。 Pi 主网协议升级仍在继续，网络现已升级至协议 21。

RPC 服务器支持什么

RPC 服务器是一个接口，允许应用程序通过发送请求和接收响应来与区块链进行通信。

开发人员：测试 RPC 服务器！

RPC 服务器目前已在 Pi Testnet 上提供，供开发人员探索和测试。

鼓励开发者尝试一下：

curl https://rpc.testnet.minepi.com \
 -H "Content-Type: application/json" \
 -d '{"jsonrpc":"2.0","id":1,"method":"getHealth"}'

基于测试网的性能和可靠性，RPC服务器也将在主网上发布。
