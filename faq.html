新手必看 FAQ

为您解答关于 Pi Network 注册、挖矿与主网的所有疑惑。

1. 什么是 Pi Network（派币）？
Pi Network 是由斯坦福大学博士团队开发的一种新型加密货币。它是全球首个可以在手机上挖掘、且不损耗电量和流量的区块链项目，目前全球拥有超过 5500 万活跃先锋。
2. 注册时必须填写邀请码吗？
是的，Pi 采用严格的邀请制以确保社区的真实性。填写官方认证邀请码 nbjh 不仅能顺利进入系统，还能立得 1 Pi 奖励，并享受中文社区的算力加成。
3. Pi 币目前价值多少？什么时候可以变现？
Pi 目前处于"封闭主网"阶段。在这个阶段，Pi 已经可以在生态内进行商品换购。真正的交易所变现将在"开放主网"阶段开启。根据官方路线图，大规模的 KYC 正在进行，这是进入开放网络的前提。
4. KYC 认证一直卡住、没收到推送怎么办？
KYC 采用分批次推送机制。如果您的账户一直没有收到，请确保已绑定手机号或 Facebook。如果遇到具体问题，建议立即加入我们的 Telegram 交流群，群内有经验丰富的志愿者为您提供一对一指导。
5. 为什么我的采矿速率变慢了？
Pi 具有减半机制。随着全球用户量的增加，基础采矿率会不断下降。要提升速度，您可以通过：1. 邀请新成员；2. 运行电脑节点；3. 锁定您的 Pi 资产；4. 在 Pi 浏览器中使用 DApp。
6. Pi 减半机制是什么？
Pi 的减半机制类似于比特币的减半设计。每当网络达到特定的用户里程碑（如 1 千、1 万、10 万、100 万、1000 万用户），基础采矿率就会减半。这一设计确保了 Pi 的稀缺性和长期价值，同时激励早期参与者。减半不会影响您已有的余额，只会影响新挖掘的速率。
7. 如何运行 Pi 节点？有什么要求？
运行 Pi 节点需要一台持续在线的电脑（Windows/macOS/Linux），稳定的网络连接，以及至少 4GB 内存和 SSD 硬盘。您需要在 Pi App 中申请节点资格，通过审核后下载官方节点软件即可开始。运行节点可以获得额外的采矿加成，同时也为 Pi 网络的去中心化做出贡献。详见我们的节点运行指南。
8. Pi 钱包怎么激活？
打开 Pi 浏览器，进入 Pi Wallet 应用，系统会自动为您生成钱包地址和助记词。请务必将助记词安全抄写在纸上，不要截图或保存在线。助记词是恢复钱包的唯一方式，丢失将无法找回您的 Pi 资产。确认备份助记词后，钱包即激活完成。
9. 什么是锁仓（Lockup）？有什么好处？
锁仓是 Pi 的一项自愿功能，您可以选择将一定比例的已迁移主网 Pi 锁定一段时间（2 周、6 个月、1 年或 3 年）。锁仓的好处：1. 获得更高的采矿速率加成；2. 锁仓比例越高、时间越长，加成越大；3. 为网络稳定性做出贡献，帮助维持 Pi 的长期价值。您可以在主网清单中设置锁仓比例和时长。
10. 开放网络和封闭网络有什么区别？
封闭网络（Enclosed Mainnet）阶段，Pi 的区块链是隔离运行的，不允许与外部交易所连接，Pi 只能在生态应用内流通。开放网络（Open Network）阶段，防火墙将被移除，Pi 可以与外部世界自由交互，包括连接交易所和跨链操作。Pi 核心团队在 2025 年 2 月正式开放了网络。
11. Pi 可以转到交易所卖吗？
开放网络上线后，Pi 理论上可以转入交易所。但目前官方尚未与任何交易所建立正式合作，部分上线 Pi 的交易所属于未经授权的行为。请务必警惕任何声称可以"高价收购 Pi"的平台，切勿将助记词泄露给第三方。官方会在正式公告中说明交易所合作的详细信息。
12. 手机挖 Pi 耗电吗？安全吗？
完全不耗电。Pi 的挖矿不需要像比特币那样进行高强度计算，您只需每 24 小时点击一次采矿按钮即可。Pi App 不会在后台消耗您的电池或流量。安全性方面，Pi 由斯坦福大学博士团队开发，代码经过严格审计，且不要求任何敏感权限。
13. 一个手机能注册多个 Pi 账号吗？
不可以。Pi 严格执行"一人一账号"政策。系统会通过手机设备 ID、KYC 身份验证等多重手段检测多账号行为。如果被发现一人持有多个账号，所有关联账号都可能被永久封禁。请遵守规则，一人只用一个账号。
14. Pi 浏览器有什么用？
Pi 浏览器是 Pi 生态系统的核心入口。通过它，您可以：1. 访问 Pi 钱包进行资产管理；2. 完成 KYC 身份验证；3. 浏览和使用 Pi 生态中的去中心化应用（DApp）；4. 参与 Pi Chat 社区交流；5. 体验 Fireside Forum、Pi Ads 等生态应用。详见Pi 浏览器介绍。
15. 什么是 Pi App Studio？
Pi App Studio 是 Pi Network 推出的低代码/无代码应用开发平台，让不具备编程经验的先锋也能创建 Pi 生态应用。它提供了可视化界面和预设模板，支持快速搭建可接受 Pi 支付的去中心化应用，大幅降低了开发者入门门槛。
16. 如何成为 Pi 开发者？
成为 Pi 开发者的步骤：1. 下载 Pi 浏览器并登录您的 Pi 账号；2. 访问 develop.pi 应用，注册开发者账户；3. 创建新应用并获取 App ID 和 API 密钥；4. 集成 Pi SDK（JavaScript）到您的网页应用中；5. 在测试网完成测试后提交上架审核。详见开发者中心。
17. Pi 的总量有多少？
Pi 的最大供应量为 1000 亿枚。其中：65% 分配给所有先锋（通过采矿获得）；10% 用于基金会支持生态发展；5% 用于核心团队；20% 作为社区储备基金。与比特币 2100 万枚的固定上限不同，Pi 的供应量更大，旨在确保全球范围内的广泛分配和实际使用。
18. 忘记密码怎么办？
如果您忘记了密码，可以在登录页面点击"忘记密码"，通过绑定的手机号或 Facebook 账号进行重置。如果您同时忘记了密码且无法访问绑定的手机号，请通过 Pi App 内的反馈功能联系官方支持团队，提供身份证明材料进行人工验证。
19. Pi 账号被锁定了怎么恢复？
账号被锁定通常是因为系统检测到违规行为（如多账号、使用自动化工具等）。恢复步骤：1. 在 Pi App 中提交申诉；2. 详细说明您的情况；3. 提供必要的身份验证材料；4. 等待核心团队的审核结果。申诉处理可能需要数周时间，请保持耐心。如果属于误封，通常会得到解决。
20. 为什么需要邀请码？
邀请码机制是 Pi Network 防止机器人刷号的核心措施之一。通过邀请制，每个新用户都需要由一个真实存在的先锋引荐，从源头保证了社区的真实性。同时，邀请机制也形成了安全圈（Security Circle），这是 Pi 共识算法的基础——通过信任链条确保网络安全。使用邀请码 nbjh 注册，还能获得额外奖励。
