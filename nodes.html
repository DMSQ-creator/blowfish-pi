什么是 Pi 节点？

节点是 Pi 生态系统中的第四个角色，运行在笔记本电脑和台式机上，而不是手机上。与其他区块链类似，Pi 节点将负责在分布式账本上验证交易，并通过共识机制算法达成一致。

不同于比特币使用的工作量证明（PoW），Pi 节点基于恒星共识协议（SCP）。在 SCP 中，节点形成信任组（法定人数切片），仅同意那些受信任节点也同意的交易。通过手机采矿形成的安全圈，在宏观上汇聚成了全球信任图，这使得 Pi 节点能够高效、低能耗地运行。

参与级别与要求

目前先锋可以通过三个不同的级别使用 Pi Node 软件：

级别 职责说明 硬件/网络要求
电脑 App 仅使用桌面界面进行聊天、查看余额。 基础办公电脑，互联网连接即可。
普通节点 验证区块链有效性，提交交易，未来可贡献存储和带宽。 稳定在线，支持 Docker 环境，建议 4 核 CPU/8G 内存。
超级节点 Pi 区块链的主干。负责运行共识算法，写入账本，同步全网状态。 24/7 全天候在线，高速且极稳的网络，需开放端口。

节点选拔标准

核心团队将根据以下标准从申请者中筛选正式节点：

  • 运行时间： 能够保持 24/7 持续在线。
  • 网络质量： 具有快速且稳定的互联网连接。
  • 开放端口： 能够在其本地路由器上进行端口转发（初级阶段要求）。
  • 硬件性能： 具有足够的处理器速度和内存容量。
  • 社区信任： 根据在 Pi 网络中的信用评分和安全圈贡献。

测试网路线图

1. 筛选阶段 (Selection Stage)

核心团队运行共识算法，校准硬件要求，并评估各节点的可靠性和连接性。此阶段将定义正式运行的阈值。

2. 修订阶段 (Revision Stage)

迭代测试共识算法的压力，模拟各种极端场景（如网络断开、大量节点下线等），以增强网络的鲁棒性。

3. 实时测试网 (Live Testnet)

节点开始处理真实数据，运行由手机采矿产生的真实交易。这是进入主网前的最后实战演习。

常见问题 (FAQ)

运行节点对设备有损耗吗？

如果您不开启 Node 功能，仅作为电脑版 App 使用，几乎不消耗资源。开启节点功能后，会占用一定的 CPU、内存和网络带宽。在测试期间，我们会持续优化性能消耗。

运行节点有奖励吗？

目前处于测试网阶段。运行节点的主要目的是测试性能。根据后续政策，为网络提供稳定贡献的节点将在主网阶段获得相应的算力加成或 Pi 奖励。
