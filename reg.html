Pi Network 在中国区 App Store 不可用，需要使用非中国区 Apple ID 才能下载。以下是注册海外 Apple ID 的详细步骤：

📌 注册美国区 Apple ID 步骤：

  1. 1. 打开 Apple ID 注册页面：https://appleid.apple.com
  2. 2. 点击"创建你的 Apple ID"

📱 选择注册方式

Pi Network 支持两种注册方式，打开 App 后在登录页面选择：

📱

手机号注册（推荐 ✅）

  • • 使用手机号+验证码登录
  • • 选择 +86 中国区号
  • • 验证码通过短信接收
  • • 方便后续账号恢复
  • • KYC 认证时更方便

📘

Facebook 注册（备用）

  • • 通过 Facebook 账号授权登录
  • • 不需要手机验证码
  • • 依赖 Facebook 账号安全
  • • 如果 FB 账号被封则无法登录
  • • 建议作为备用登录方式绑定

💡 推荐方案

首选手机号注册，注册成功后再在设置中绑定 Facebook 作为备用登录方式。这样即使手机号变更，也能通过 Facebook 登录账号。

📝 填写注册信息

Step 1：输入手机号

  • • 在国家/地区下拉框中选择 China (+86)
  • • 输入你的手机号码（11位，不需要加+86前缀）
  • • 点击"Go"或"下一步"
  • • 等待接收6位验证码短信（通常1-3分钟内到达）
  • • 输入验证码完成手机号验证

Step 2：设置密码

  • • 密码长度至少 8位
  • • 必须包含大写字母、小写字母和数字
  • • 建议使用有意义的短语组合，如：PiNetwork2026!
  • • ⚠️ 请务必记住密码，或安全保存到密码管理器

🚨 姓名填写——极其重要！

填写真实姓名是注册过程中最关键的一步：

  • • 姓（Last Name）：填写身份证上的姓，如"张"
  • • 名（First Name）：填写身份证上的名，如"三"
  • • ⚠️ 姓名必须与身份证完全一致！否则后续无法通过 KYC 实名认证
  • • 不要使用昵称、网名、英文名
  • • 姓名一旦提交极难修改，修改需要重新提交审核

Step 3：选择用户名

  • • 用户名是你在 Pi Network 中的唯一标识
  • • 只能包含字母和数字，全局唯一，不能与已有用户重复
  • • ⚠️ 用户名一旦确定无法修改！
  • • 建议使用有辨识度的名称，方便他人记住你
  • • 如果提示"用户名已存在"，换一个即可

  • • 超过24小时未点击，挖矿将暂停，不会补回损失的时间
  • • 建议设定每天固定时间点（如早上起床后），养成习惯

❓ 注册常见问题 FAQ

📱 收不到手机验证码怎么办？

收不到验证码是比较常见的问题，尝试以下方法：

  • • 检查手机信号是否正常，尝试切换飞行模式后恢复
  • • 查看短信是否被手机安全软件拦截（如360、腾讯管家）
  • • 等待3-5分钟后重新发送验证码
  • • 部分虚拟运营商号码可能无法接收，建议使用三大运营商号码
  • • 如果始终收不到，可以尝试使用 Facebook 方式注册
⚠️ 用户名已存在怎么办？

Pi Network 的用户名是全局唯一的，如果提示已存在，说明有人先注册了这个名字。

  • • 换一个用户名即可（添加数字或字母组合）
  • • 建议在用户名中加入生日数字或特殊字符，增加唯一性
  • • ⚠️ 用户名确定后无法修改，请谨慎选择
🪪 姓名填错了怎么办？

姓名填错是一个严重问题，因为它直接影响 KYC 认证能否通过。

  • • 如果刚注册，立即在 Profile 页面尝试修改
  • • 如果系统不允许自行修改，需要提交姓名更改申请（Name Change Request）
  • • 进入 App → 菜单 → Profile → 点击姓名旁边的编辑按钮
  • • 提交修改后需要等待 Pi 团队审核，可能需要数周
  • • ⚠️ 修改次数有限，请务必一次改对
🔢 一个手机号能注册几个账号？

一个手机号只能注册一个账号。

  • • Pi Network 严格执行一人一号制度
  • • 系统会检测多账号行为，违规可能导致所有关联账号被封
  • • 不要尝试用家人手机号注册多个账号在同一设备上
  • • 家庭成员每人用自己的手机和手机号注册是允许的
⏱️ 注册后多久可以开始挖矿？

注册完成后立刻就可以开始挖矿！

  • • 完成注册流程后，进入首页点击闪电图标即可
  • • 不需要等待审核或额外步骤
  • • 建议注册后第一时间点击闪电，不要浪费任何一个24小时周期
🔑 忘记密码怎么办？

忘记密码可以通过以下方式找回：

  • • 在登录页面点击"Forgot Password"
  • • 如果用手机号注册，通过短信验证码重置密码
  • • 如果绑定了 Facebook，可以通过 Facebook 登录后在设置中修改密码
  • • 重置密码后建议记录到安全的地方
📱 手机丢失/换手机怎么办？

手机丢失或换手机不会丢失你的Pi账号和余额：

  • • Pi 账号数据保存在服务器上，不是保存在手机本地
  • • 在新手机上下载 Pi App，用原来的手机号/密码登录即可
  • • 如果绑定了 Facebook，也可以用 Facebook 登录
  • • ⚠️ 登录后可能需要重新验证手机号
  • • 建议提前绑定 Facebook 备用登录，以防万一
📞 能否更换绑定的手机号？

可以更换，但操作需要谨慎：

  • • 进入 App → 菜单 → Settings → Account → 更换手机号
  • • 需要验证旧手机号和新手机号
  • • 如果旧手机号已无法接收验证码，需要联系 Pi 官方客服
  • • ⚠️ 更换手机号期间不要卸载 App，以免账号丢失
  • • 强烈建议在更换前先绑定 Facebook 作为备用登录方式
🌍 注册时选错了国家/地区怎么办？

选错国家区号可能导致无法收到验证码：

  • • 如果还在注册页面，直接返回重新选择 +86 China
  • • 如果已经用错误区号完成了注册，需要在设置中修改手机号
  • • 中国大陆用户务必选择 +86 区号
