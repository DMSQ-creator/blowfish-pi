发展路线图

Pi Network 的愿景是建立世界上最具包容性的 peer-to-peer 生态系统，由全球使用最广泛的加密货币 Pi 驱动。为了实现这一愿景，我们将项目划分为三个主要阶段，每个阶段都承载着独特的技术和社区使命。

第一阶段：设计、分发、信托图引导

起步与愿景确认 (2019)

在这一阶段，Pi 服务器作为模拟分散系统行为的中心运行。由于主网尚未启动，用户在手机上的操作实际上是在与中心化服务器交互，以累积未来的主网信用。这一阶段的核心是验证我们的“移动采矿”理念——即通过社交信任而非昂贵的硬件来安全地分发代币。

我们在这个时期成功实现了全球范围内的爆发式增长，数百万 Pioneers 加入了网络，并建立了庞大的安全圈。所有的挖掘数据都被详细记录，以便在主网启动后进行最终的映射转换。这是 Pi 历史上最重要的“共识积累”时期。

第二阶段：测试网 (Testnet)

节点、区块链与生态系统构建 (2020)

2020 年，Pi 迈出了去中心化的关键一步——上线测试网。我们在全球范围内分发了节点软件（Pi Node），让数万名拥有电脑的先锋能够参与到区块链的共识验证中。这个阶段的任务不仅是测试 SCP 算法在真实网络环境下的稳定性，更是为了让开发者能够开始在 Pi 浏览器上构建和测试应用（dApps）。

测试网不仅仅是技术实验，它是 Pi 经济价值的试炼场。通过测试网，我们确立了 Pi 钱包的安全性、Pi 浏览器的交互规范以及 SDK 的易用性。数百万次的测试交易为最终的主网启动提供了宝贵的数据支撑。

第三阶段：主网 (Mainnet)

A. 封闭网络阶段 (Closed Network)

这是我们目前所处的关键历史时刻。主网于 2021 年底正式启动，但通过特殊的防火墙保护，暂时切断了与外部区块链的连接。这一设计的精妙之处在于：它为我们的生态系统提供了一个“育婴室”。

在封闭期间，我们集中精力完成两件史无前例的大事：

  • 大规模身份验证 (KYC)： 利用全球分布式验证系统，确保每一个迁移到主网的账户都对应一个真实的独立人类。这是为了彻底杜绝机器刷票，维护每一位 Pioneer 的利益。
  • 主网余额迁移： 将数千万先锋累积的余额，分批次安全地映射到真正的区块链账本上。目前的迁移速度已经通过算法优化提升了 300% 以上。
  • 应用实用性培育： 鼓励开发者在封闭环境下开发真正的“以物换物”应用，让 Pi 币在进入交易所之前就已经具备了真实的商业消费能力。

B. 开放网络阶段 (Open Network)

这是 Pi 愿景的终极实现。我们将移除防火墙，让 Pi 区块链与外部世界彻底互联。届时，Pi 将能够与任何其他区块链通信，并在全球交易所进行自由交易。这一阶段的开启取决于我们社区在 KYC 覆盖率和生态系统成熟度上是否达到了既定目标。
