WHITEPAPER

01. 项目背景与使命

随着互联网从 Web2 向 Web3 的转型，数字货币已成为全球金融演进的必然。然而，第一代加密货币（如比特币）在实际运行中创造了巨大的社会经济障碍。算力高度集中、能效低下、对普通人极高的准入门槛，让 99% 的人被排斥在区块链的所有权之外。

Pi Network 的初衷是建立全球最包容、最公平的 P2P 经济体。我们致力于让每一个拥有手机的人，都能平等地参与到货币的铸造与治理中。通过利用社交信任图谱，我们旨在打破算力霸权，实现真正的去中心化愿景。

02. 第一代区块链的问题：工作量证明的局限

比特币引入的‘工作量证明 (PoW)’在早期是划时代的。但在今天，它已演变成一场算力军备竞赛。ASIC 矿机的普及使得普通用户的 CPU 毫无竞争力，记账权被极少数拥有低价电力的矿场主垄断。

此外，PoW 的能源消耗已达到国家级水平。在 2026 年强调绿色能源的背景下，这种高能耗机制正面临严峻挑战。Pi 通过不基于算力竞赛的共识逻辑，实现了几乎零能耗的运行，彻底解决了能源与权力集中的双重痛点。

03. 核心突破：恒星共识协议 (SCP) 的 Pi 实现

Pi 并没有使用比特币的竞速模式，而是采用了基于‘恒星共识协议’的联邦拜占庭协议 (FBA)。其核心创新在于‘法定人数切片 (Quorum Slices)’。

在 Pi 网络中，节点不需要全网广播算力。通过‘安全圈’提供的社交信任数据，网络自发地形成了一张全球信任图。这使得 Pi 能够实现秒级的交易确认，且对手机 CPU 的占用几乎为零，这就是 Pi 能够在手机上运行的底层技术保障。

04. 代币经济学：基于人类贡献的采矿模型

Pi 的分发模型旨在平衡先发优势与长期网络扩张。我们的挖掘速率公式由四个维度组成：

M = I(基础) + S(安全圈) + R(邀请) + E(生态贡献)

减半逻辑： 当用户数每跨越一个 10 倍量级，挖掘速率即减半。这种设计借鉴了黄金的边际开采成本增加原理。同时，所有余额映射到主网前必须通过 KYC，确保了每一枚代币的背后都是一个真实的人类，彻底剔除了机器人生成的虚假资产。

05. 项目路线图：迈向开放主网的战略演进

Pi 的发展分为三个主要时期，每一个阶段都有明确的退出标准和进入条件。

当前：封闭主网阶段 (Closed Mainnet)

主网已运行，但受限于防火墙，禁止外部连接。这一时期的设立旨在：1. 全员通过 KYC 身份认证；2. 将手机余额映射到主网；3. 在无投机干扰下，培育真实的商业实用性。我们要让 Pi 在开放交易前，就已经在现实世界中‘有用’。

未来：开放主网阶段 (Open Mainnet)

满足 KYC 覆盖率和生态繁荣目标后，我们将撤销防火墙。届时，Pi 将连接全球交易所、外部钱包，正式成为全球数字货币海洋的一员。共识将在此刻化为真正的全球价值。

结语：去中心化的终极使命

Pi Network 不仅仅是一场技术实验。它是一场关于人类社会如何重新定义‘价值’与‘信任’的社会协作工程。感谢每一位先锋的坚守，我们正一步步接近那个‘权力归于大众’的未来。
