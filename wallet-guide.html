Wallet

Pi 钱包是什么

Pi Wallet 是 Pi Network 的官方数字钱包，所有先锋用户均可通过 Pi Browser 访问。它基于 Pi 区块链构建，属于非托管钱包——这意味着你对资产拥有完全控制权，任何人（包括 Pi 核心团队）都无法动用你的 Pi。

🌐

Pi Browser 访问

钱包集成在 Pi Browser 中，打开即可使用，无需额外下载独立 App

⛓️

基于区块链

所有交易记录上链，公开透明、不可篡改，安全可靠

🔐

非托管钱包

私钥由你自己掌握，只有你能操作资产，真正去中心化

钱包创建步骤

1

打开 Pi Browser

下载并打开 Pi Browser 应用，使用你的 Pi 账号登录

2

创建钱包

在 Pi Browser 首页点击「Pi Wallet」，按提示创建你的钱包

3

备份助记词 ⚠️

系统会生成一组助记词，务必手抄保管，切勿截图或在线存储！丢失助记词 = 永远丢失你的 Pi！

🚨

助记词是最重要的安全凭证

助记词是恢复钱包的唯一方式。如果你丢失了助记词，没有人（包括 Pi 核心团队）能帮你找回资产。建议将助记词手写在纸上，存放在安全的物理位置，不要拍照、不要截图、不要存在手机或电脑上。

Pi 转账操作

主网开放后，Pi 链内转账已完全可用。以下是详细的转账操作指南。

📤 链内转账步骤

  1. 1打开 Pi Browser，进入 Pi Wallet
  2. 2点击「Send / 发送」按钮
  3. 3输入收款方的 Pi 钱包地址
  4. 4输入转账金额，确认交易详情
  5. 5输入钱包密码确认，提交交易

📱 扫码转账

  1. 1请收款方展示其钱包二维码
  2. 2在 Pi Wallet 中点击扫码图标
  3. 3扫描对方二维码，自动填入地址
  4. 4输入金额，确认并提交转账

💡 转账注意事项

  • • 转账前务必核实收款地址，Pi 链上交易不可逆
  • • 大额转账前建议先小额测试，确认地址无误后再转全款
  • • 确认收款方已完成 KYC，否则可能无法到账
  • • 转账后可在区块浏览器查询交易状态

💸 转账费用说明

目前 Pi 链内转账手续费为零，这是 Pi Network 的重大优势之一。Pi 核心团队采用了不同于以太坊 Gas 费的共识机制，让先锋们可以零成本转账。

未来如果调整费率，核心团队将提前公告。请以官方最新通知为准。

Safety

安全须知

在 Pi Network 生态中，安全是第一位的。请务必牢记以下安全准则，保护你的数字资产。

🚫 助记词绝对不能泄露

助记词 = 你钱包的万能钥匙。任何知道你助记词的人都可以转走你所有的 Pi。

  • • 永远不要把助记词发给任何人
  • • 不要将助记词输入任何非官方应用
  • • 不要拍照、截图保存在手机上
  • • 建议手抄多份，分别存放在不同安全位置

🕵️ 不会有人官方私信你要助记词

Pi 核心团队和官方客服绝对不会私信你索要助记词、密码或任何敏感信息。

  • • 凡是私信你要助记词的，100% 是骗子
  • • 凡是承诺帮你操作钱包的，100% 是骗子
  • • 凡是声称"官方客服"加你好友的，务必核实
  • • 官方信息只通过 Pi App 内公告和官网发布

🛡️ 警惕 Pi 诈骗

  • • 不点击来源不明的链接，警惕钓鱼网站
  • • 不下载非官方 Pi 应用，谨防恶意软件
  • • 不参与任何承诺高回报的 Pi 投资项目
  • • 不轻信"P i 内部价""官方渠道出售"等话术
  • • Pi 目前没有官方的场外交易渠道

✅ KYC 认证的重要性

KYC（Know Your Customer）身份认证是 Pi 主网迁移和交易的必要步骤。只有通过 KYC 的先锋才能：

  • ●将 Pi 从手机余额迁移至主网钱包
  • ●在主网进行转账和交易
  • ●在交易所出售 Pi
  • ●参与 Pi 生态应用支付
